## 1 回目からの変化(写真で確かめたもの)

- `/mouse`:入力前に「比べられません」が出なくなった(入力の箱の下は注記だけ)。結果では、比べられない段が右の列の中に入った(1440 で左の列とそろう)。寸法・件数がマゼンタ(本文の書体)。375 の絞り込みは `<details>` に畳まれ、「すべて表示中」「3 つの条件で絞り込み中」と今の状態が summary に出る。1 位の行は、375 で約 1,100px(1 回目は約 1,700px)。カードの店のリンクが 1 行にそろい、「このマウスのソール」も同じ並び。
- `/pads`:縮尺図「パッドの上のマウス」が表の右(375 は下)に出る。絞り込んだサイズだけ線がパープルになる(`pads-filter-r2-375-list.png`)。上の数字が絞った数になり、説明が「絞り込みに合う数(全 41 枚)」に変わる。375 の絞り込みが畳まれ、一覧は約 600px から。表の列がそろい、数字がマゼンタ。「公式ページ」の左の下がりがなくなった。
- `/skates`:1440 の行が 1 列になり、素材・入数・厚さの 3 列が約 250px ずつ。1 文字だけの行がなくなった。「マウスを選ぶ」の箱に 1 製品 = 1 マス(専用 = 面・汎用 = 線)。行の頭にも同じマス。数字の厚さには 0〜1.5mm の線の目盛り(`skates-mouse-r2-375-thickness.png`)。選ぶ欄の文字が短くなり、375 で切れない。

## 新しく見つかったもの・残っているもの

1. **0 件のときの上の大きな「0」が、マゼンタの四角に斜線の記号に見える**(`pads-zero-r2-375.png`・`skates-zero-r2-375.png`)。Orbitron の 0 を display-2 で出しているため。0 件の画面で一番大きな要素が「禁止」の印に読める。見出しの件数(本文の書体)は直ったが、ここだけ残った。
2. **チップの文字が右に寄る**:選んでいないチップも、チェックの印の場所を `invisible` で取るようになり、左に 16px+隙間の空きができた(`pads-normal-r2-1440-first.png` の「布」「S」、`skates-mouse-r2-375-list.png` の「PTFE」)。並びの入れ替わりは止まったが、文字が真ん中にないチップが 1 画面に十数個並ぶ。`/mouse` の `ChipButton` は印がないので、3 画面でチップの形がそろわない。
3. `/pads` の縮尺図:
   - 375 で、小さいサイズの名前の札(「Medium」「Small」)が重なり、平均のマウスの面をほとんど隠す(`pads-normal-r2-375-scale.png`、QcK)。
   - 縮尺が行ごと(その行の一番大きいサイズに合わせる)なので、1 行だけのパッド(G240 340×280mm)と QcK の 5XL(1600×800mm)が同じくらいの大きさに見える。マウスの面の大きさで分かるが、行をまたいで大きさを比べにくい。
   - 図の説明(2〜3 行)が 41 行すべてに出て、375 の全体が 33,920px(1 回目 27,174px)。
4. `/skates`:
   - 絞り込み 0 件(`?material=UPE&shape=full`)で、上の「0 件」の説明が「公式の数字で比べられる数」のまま(`/pads` は「絞り込みに合う数(全 41 枚)」)。
   - 375 で見出しが 2 行になると、件数の「13」と「件」が縦に分かれる(`skates-mouse-r2-375-list.png`・`skates-dedicated0-r2-375-list.png`)。
   - 375 の絞り込みは畳まれていない(マウスを選ぶの箱+マス+絞り込みの箱のあと、一覧は約 1,100px から)。
   - 絞り込みの箱の中の「絞り込みを外す」(ghost)が 16px 下がる(`skates-zero-r2-375.png`)。
5. `/mouse`:1 位の行の「合う度 100」が小さな Orbitron のままで、0 が斜線入りに見える(`TopMouseRow.tsx:28`)。2 位からの「99」は大きいので読める。
