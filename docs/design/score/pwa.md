### 判定

- **3 つとも不合格**。3 つに共通して、点が一番低いのは Creativity(6.5)です。
- 先に CEO・社長の判断が要ります。小さな道具(案内の段・オフラインの 1 枚)に、Creativity と Design ①(大きな文字の差)を当てはめるかどうか。前に規約のページで同じ問いを出しています(`final-summary.md` 5 章)。
  - 当てはめない場合、Creativity と Design ① を外して Design・Usability・Content だけで見ます。下の P1 を入れれば約 8.0〜8.3 です。
  - 当てはめる場合は、下の P0 が要ります。どちらでも P1 は要ります。

### 直すこと(優先順)

1. (P0・Creativity ①②、Design ③)**案内にアプリのアイコンそのものを出す**:`src/components/pwa/InstallHint.tsx:82-100` の `body` を `grid gap-4 sm:grid-cols-[64px_minmax(0,1fr)]` にし、左にドット絵の「ロ」(8×8 のマス、1 マス 8px で 64px)を置く。`offline.html` と同じ絵で、`public/icons` と同じ色。
   - 下に 12px で「ホームに並ぶアイコン」と書く。「何がホームに増えるか」がマスの言葉で一目で分かる。
   - `/aim` の 1440 の右の空きも埋まる(カードの中身は `max-w-[720px]` までにする)。
2. (P0・Creativity ③)**開くと答える**:`<details>` を開いたら、アイコンの横に、1 マス 8px の 4×1 の「ホームの列」(線の四角 3 つ+アイコン)を出す。CSS の `group-open:` だけで、動きは付けない(段で出るだけ)。開く操作に見た目が答える。
3. (P0・`offline.html` の Design ① と Creativity)**「途切れた線」**:「ロ」を大きくする(375 で 1 マス 16px = 128px、1440 で 24px = 192px。表示の段に当たる大きさ)。
   - 下に横の線を 1 本引き、真ん中を 32px 切る。線の言葉で「途切れた」を伝える。
   - ボタンに `:hover` / `:focus-visible` で、切れ目の線が `opacity` でつながる。CSS だけで 200ms、reduced-motion ではすぐ切り替える。
   - JS も外の CSS も足さないので、設計の決まり(JS なし・外のフォントなし)の中でできる。
4. (P1・Usability ①)**開閉の印**:`InstallHint.tsx:96` の `summary` に lucide の `ChevronDown`(16px)を足し、`group-open:rotate-180`(動きなし)にする。三角が出ない `inline-flex` の代わりの印になる。
5. (P1・Design ③)**番号の高さ**:`src/components/pwa/InstallSteps.tsx:8` の番号を `text-sm leading-6`(文と同じ行の高さ)にし、1 行目にそろえる。
6. (P1・Design ③)**アイコンの抜け**:`InstallSteps.tsx:9` の空きの代わりに、手順ごとにアイコンを入れる。iPhone の 3「追加」は `CirclePlus`、PC の 2「インストール」は `AppWindow`。どの手順にもアイコンがある形にそろえる。
7. (P1・既知)番号の `aria-hidden` を外すか、`li` の頭に `<span className="sr-only">手順 {n}:</span>` を足す。

- 見込み:
  - 当てはめる場合:1〜6 で Design 8.0〜8.5・Usability 8.0〜8.5・Creativity 8.0 → `/my` と `/aim` は約 8.2〜8.4。offline は 3 で Design 8.0・Creativity 8.0 → 約 8.0〜8.2。
  - 当てはめない場合:4〜7 だけで 3 つとも約 8.0〜8.3。

### 判定

- `/aim` のカードは合格(8.20)。`/my` の段(8.15)と `offline.html`(8.10)は不合格。どちらも 4 観点すべて 8 以上で、条件の抜けはない。足りないのは「基準より上」の観点。
- **届くための最小の直し**
  1. (P0・`/my`・Content → 8.5、平均 8.20)`src/components/pwa/InstallHint.tsx:56` の `/my` の 1 行を、できるようになることが分かる言い方にする。例:「アプリのように全画面で開けます。アイコンを長押しすると、今日の文字・仲間・マウス探しにすぐ行けます。」
     - 長押しのショートカットは manifest の `shortcuts`(/aim・/lobby・/mouse)にある本当の機能。ただし iPhone にはないので、後ろの文は `platform` が `android` / `desktop` のときだけ出す。iPhone は「アイコンから 1 回で開けます。」。
  2. (P0・`offline.html`・Design → 8.5、平均 8.30)
     - 中身のまとまりを画面の真ん中に置く:`public/offline.html:22` の `main` を `width: fit-content; margin: 0 auto`。
     - PC(`min-width: 1024px`)の h1 を 32px(段の中)にし、ロ 192px・h1 32px・本文 16px の 3 段にする。
     - 縦の間を 8 の倍数にそろえる(今は ロ と線の間 24、線と h1 の間 24+8)。
  3. (P1・`offline.html`・Content → 8.5)説明を「つながったら、もう一度読み込むと、開こうとしていたページに戻ります。」にする。`href=""` で今の URL を読み直すので本当のこと。2 と合わせて平均 8.35。
  4. (P2・`/aim`)閉じた形では、アイコンを右の端に寄せる(開いたときだけ左へ 3 マス分の列が伸びる)。`InstallHint.tsx` のアイコンの列を `justify-items-end`。
  5. (P2・`/my`)1440 では、アイコンとホームの列を段の右に置く 2 列(`/aim` のカードと同じ並び)にして、右半分の空きを使う。
