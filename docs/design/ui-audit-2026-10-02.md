### 2-2. フォント

- 読み込み(`src/app/layout.tsx:9-10`):
  - Zen Kaku Gothic New 500/700、`subsets: ["latin"]` だけ。日本語の部分の先読みがない(表示はされるが、最初の表示で文字が遅れて入れ替わる可能性。要確認)。400 がないので、指定なしの本文は 500 で出る。
  - Orbitron 700/900(英字・数字)。
- 使い方:Orbitron は `font-[family-name:var(--font-display)]` を 12 ファイル・約 16 か所で直書き。ユーティリティ名(`font-display` など)はない。
- 不具合:`globals.css:67-68` が `--font-heading: var(--font-sans); --font-sans: var(--font-sans);` と**自分自身を参照**している。`html { @apply font-sans }`(`globals.css:150-152`)は無効になる。いまは body の指定が効いているので見た目は崩れていない。
- 見出しの書体:日本語の見出しも本文と同じ Zen Kaku Gothic の太字だけ。ネオンの世界観を出すのは `rl-glitch` の 3 か所(ヘッダーのロゴ、トップのタイトル、タイプ名)だけ。

## 3. 画面ごとの所見

凡例:状態 = 空 / 読み込み中 / エラー / 成功

### ヘッダー・フッター(`brand/SiteHeader.tsx`、`brand/SiteFooter.tsx`)
- 目的:どこからでも 7〜8 の機能へ行ける。
- 優先順位:✗。リンク 7〜8 個+ベルが同じ重さで並ぶ。今いるページの印(`aria-current` や色)がない。
- 375px:ロゴ(`shrink-0`)の右に、`flex-wrap` の小さいリンクが 2〜3 行に折り返す。メニューの形がない。押せる高さは約 20px で、44px に足りない。
- フッター:リンク 3 つが `text-xs` で、押せる高さが小さい。

### `/`(トップ、`src/app/page.tsx`)
- 目的:「今日はなにしに来た?」から 3 つの入口へ。
- 優先順位:✗。入口は診断・感度・仲間の 3 つだけ。D20 で「何度も来る理由」とした**今日の文字**と、収益の入口の**マウス探し**・**マイ設定**がトップにない。
- 見た目:絵文字のアイコン、同じ絵の 16 個のアイコン。ヒーローは文字だけで、ブランドの印象が弱い。
- 状態:静的なので問題なし。
- 離脱しやすい点:初めて来た人に「このサイトは何か」の説明が 1 行もない(タグラインは英字の小さい文字だけ)。

### `/diagnosis`(`diagnosis/DiagnosisClient.tsx`、`QuestionCard.tsx`)

- 気になる点:h1 がない。始める前の画面がなく、いきなり Q1(何問・何分・結果で何が分かるかが見えない。`metadata` のタイトルにしかない)。選んだら自動で次へ進むが、押した手応え(選ばれた色)が一瞬しか見えない。

## 5. 直す点の一覧と、社長に聞く論点

### 5-1. 優先度つきの直す点

**高(公開前に直したい)**
1. 共通部品を作り、直書きを置き換える:Button(主・二番手・文字だけ・危険)、Card、Input/Select、Chip、PR の札、セクション見出し。shadcn の `ui/` を `--rl-*` に合わせて使うか、作り直すかを決める(論点 2)。
2. フォーカスの線を全体で決める(シアンの 2px の線+少しずらす)。`--ring` を `--rl-*` にする。
3. ホバー・押した状態・`cursor-pointer`・`disabled` の見た目を、1 の部品に入れる。
4. 絵文字と文字の矢印を SVG アイコン(`lucide-react`)に置き換える。
5. モバイルのヘッダーを作り直す(下のタブバーかメニュー。今いる場所の印。押せる高さ 44px)。
6. シアンを「押せるもの」だけにする。数字の強調はマゼンタ、選ばれている状態はパープルの枠にそろえる(`--rl-border` の色も見直す)。
7. パープルの文字(`MouseCard.tsx:47`、`ProCard.tsx:30`)とベルの数字(`Bell.tsx:75`)のコントラストを直す。入力欄の枠を 3:1 以上にする。
8. トップの入口を今の機能に合わせる(今日の文字・マウス探しを入れる。論点 3)。
9. `loading.tsx` を `/lobby`・`/aim`・`/c/[slug]` に足す。`error.tsx` にトップへの道を足す。
10. 16 タイプのアイコンが全部同じ問題を、公開までにどうするか決める(論点 4)。

**中**
11. 文字サイズの段階を決める(12/14/16/20/24/32 など)。エラー文は 14px 以上にする。h2 をそろえる。
12. 角丸を 3 段階にする(入力・小さい部品/カード/丸いボタン)。面と枠の白の透明度 6 通りをトークン 2〜3 個にまとめる。
13. ページの幅を 2 段階にする(読み物・フォーム用/一覧・道具用)。PC でヘッダーと幅をそろえる。
14. `/mouse` で Amazon・楽天のボタンを主役に近づける(シェアは二番手へ)。
15. `/my` を区切る(必須/任意、埋まり具合、名刺のプレビューを上か横に)。塗りのボタンを 1 つにする。
16. `/lobby` 未ログインの画面に、流れ(声かけ → 相互 OK → Discord 名)と安全の説明を足す。
17. 診断の前に短い始める画面(12 問・1 分半・分かること)と h1 を足す。
18. 感度計算で「マイ設定に保存」を結果の下へ。
19. 長い名前・自己紹介に `break-words` / `min-w-0`(`CandidateCard`、`Ranking`、`MouseCard`)。
20. ラベルのない欄(ロビーの絞り込み、通報)と、色の丸の名前を直す。`LoginButton` に押している間の状態を付ける。

**低**
21. `globals.css` の片付け:`--font-sans` の自己参照(`:67-68`)、使っていない shadcn の白テーマと `@layer base` の body。
22. Orbitron を `font-display` のユーティリティにする。`#1b1f45` と Discord の色をトークンにする。`PixelIcon` の hex をトークンから読む。
23. `prefers-reduced-motion` で `animate-pulse` と `transition` を止める。
24. ネオンらしい奥行き(グローの影 1〜2 段階)を決めて部品に入れる。
25. ファビコン・アプリのアイコン(D29 のドット絵のシンボルマーク)と、`public/` の初期の SVG の片付け。
26. Zen Kaku Gothic New の `subsets` と、日本語の表示の速さを本番で確かめる。

### 5-2. デザインシステムを作り直すときに社長に聞く論点

1. **シアン(押してほしい色)の使い道**
   - A(おすすめ):押せるもの専用。数字の強調はマゼンタ、選んだ状態はパープルの枠、枠線は白の透明にする。
   - B:今のまま(数字や枠にもシアンを使う)。
   - C:押せるものはシアン、枠だけはシアンの薄い色を残す(ネオン感を優先)。
2. **部品の土台**
   - A(おすすめ):入っている shadcn/ui(base-ui)を `--rl-*` の色・角丸に合わせて使う(設計書 3-3 どおり。フォーカスや disabled が最初から入っている)。
   - B:ロビラボ専用の小さな部品集を自作する(見た目の自由度は高いが、手間が増える)。
   - C:今の直書きのまま、クラス名だけそろえる。
3. **スマホのナビ**
   - A(おすすめ):画面の下にタブバー(今日の文字・診断・マウス・仲間・マイ設定の 5 つ)。アプリ(PWA、D19)にもそのまま使える。
   - B:右上のメニューボタン(開くと全部のリンク)。
   - C:今の折り返しのまま、文字を減らす。
4. **トップの主役**
   - A(おすすめ):今日の文字を一番上(毎日来る理由)、その下に「自分を知る/感度・マウス/仲間を探す」の入口。
   - B:今の 3 つの入口に、今日の文字とマウス探しを足して 5 つ並べる。
   - C:今のまま 3 つ。
5. **16 タイプのアイコン(公開に間に合わない場合)**
   - A(おすすめ):社長のドット絵ができるまで、軸の組み合わせで形と色が変わる仮のドット絵を 16 種類作る(後で差し替え)。
   - B:公開までに社長がドット絵を描く(作業量に注意)。
   - C:今の同じ絵のまま公開する。
