## ページの形(公式)
- 各キャラのページに「役割(殺人鬼/生存者)」「難易度(殺人鬼だけ)」「紹介文」「能力の説明(殺人鬼)」「固有パークの説明」「伝承」がある。
- **公式の「役割」は殺人鬼/生存者の 2 つだけ。チェイス・ステルス・設置、引きつけ役・救助役・修理隠密はサイト独自の分類**(設計書 3-3 のとおり)。`officialRole` には公式の表記(「殺人鬼(難易度:普通)」など)を入れた。
- 難易度の表示は殺人鬼にだけある(簡単/普通/難しい/かなり難しい)。

## 代表の選び方(pickedBy)
- `official-beginner`: トラッパー・レイス。公式ページの難易度が「簡単」。公式が「初心者向け」と書いた文は見つからなかったので、難易度の表示を根拠にした(CEO が違うと見るなら `free` か `variety` に直す)。
- `free`: ヒルビリー・メグ・クローデット・ドワイト・ジェイク。公式ページに「チャプターDLCの内容」の欄がない = 基本ゲームのキャラ。**ただし「最初から無料で使える」と公式が書いた文は取れていない**(基本ゲームに入っているだけで、キラーの解放方法は未確認)。厳密に言うなら「基本ゲームのキャラ」。
- `variety`: 上の 2 つで足りない型の 2 体目・予備。公式の説明の向きが違うキャラ(例: ハグはトラバサミでなく幻像の罠、スピリットはステルスの別の形)。
- 殺人鬼はチャプターのキャラを含む。

## 版権(ライセンス)キャラを代表から外した件
- 外したのは、他社の作品由来のキャラ。公式サイトのキャラ一覧に出ている全 92 体(殺人鬼 40・生存者 52)のうち、私の判断で約 36 体(殺人鬼 15: ドラキュラ・ヴェクナ・ゼノモーフ・ネメシス・ウェスカー・貞子・三角頭・喰種・ファースト・デモゴルゴン・ゴーストフェイス・ピッグ・ナイトメア・レザーフェイス・スラッシャー(ジェイソン)/ 生存者 21: イレブン・ダスティン・リック・ミショーン・トレバー・ララ・アラン・リプリー・ニコラス・ケイジ・ガブリエル・エイダ・レベッカ・ジル・レオン・シェリル・ナンシー・スティーブ・アシュレイ・デイビッド・タップ・クエンティン・ビル)。
- 理由: 権利が BHVR 以外の会社(映画・ゲーム・ドラマの権利者)にもあるため。BHVR の規約でも、第三者のコンテンツは別の許諾が要ると書かれている(policy-dbd.md)。
- **「公式に版権の表記がある」ことを確かめたのではなく、キャラの由来(見た目・名前・紹介文)から私が判断した**。迷ったもの: ゴーストフェイス(他社との許諾のキャラとして扱い外した)、スラッシャー(紹介文に「ジェイソン」とあるので外した)。ビルは公式ページに作品名の表記はないが、由来から外した。
- 残したのは BHVR のオリジナルのキャラだけ(ヒルビリー・ハントレス・ナース・ブライト・レイス・スピリット・ドレッジ・トラッパー・ハグ・スカルマーチャント、メグ・ネア・デイビッド・クローデット・ドワイト・アダム・ジェーン・ジェイク・フェン・結衣)。スピリット・鬼系は日本の舞台のチャプターだが BHVR のオリジナル。

## 札(evidence)と matchable の決め方
- 札は 3-2 の表の言葉(または同じ意味の語)が公式の原文にあるものだけ。**同じ意味の語でつないだもの(CEO が確認してほしい)**:

  - ジェーン ally: 固有パークの説明の「他の生存者を治療する」を「回復」とみなした

### matchable の根拠(`roleBasis` という任意の項目を足した)
設計書 3-1 の型にはない項目 `roleBasis: { text, url }`(型を示す公式の原文 40 字まで+URL)を、matchable な全 DbD キャラに付けた。「`matchable` のキャラは札の根拠かロールの公式の根拠がある」の検査(設計書 8 章)で、札がないキャラ(スピリット・ブライト・フェン・ミン)も通すため。**型に足すか、検査の方を変えるかは CEO が決める**。`char-data.ts` が余計な項目を拒むなら、この項目だけ消せば 3-1 の型どおりになる。

| 型の判断に使った語 | 内容 |
|---|---|
| チェイス | 「追跡を終わらせる」(ハントレス)、「追跡を終える」(ナース)、「連続突進…プレッシャーを与える」(ブライト) |
| ステルス | 「気配をほとんど悟られることなく」(レイス)、「知らぬ間に攻撃を受ける」(スピリット)、「不意打ちのチャンス」(ドレッジ) |
| 設置 | 「罠を仕掛け」(トラッパー・ハグ)、「ドローンをマップ上に配置」(スカルマーチャント) |
| 引きつけ役 | 「必要な時間稼ぎをする」(メグ) |
| 救助役 | 「治療するプロ」(クローデット)、「チームの効率性を…高める」(ドワイト)、「他者を救う」(アダム)、「周りと協力する」(ジェーン) |
| 修理・隠密 | 「気配を隠すのが得意」(ジェイク)、「発電機の修理時の音が低減」(フェン・ミン。固有パークの説明) |

## 迷ったこと・注意
- 公式の紹介文は、ページの機械翻訳で表記ゆれ・誤植がある(例: 「獲物の追跡し攻撃する」)。原文のまま引用した。
- ネアのページの名前表記は、サイトマップでは「ネア・カールソン」。英語は公式の URL スラッグ(nea-karlsson)から。名前の英語表記(nameEn)は、公式の日本語ページに英語の名前が載っていないので、URL のスラッグとゲーム内の通称から私が付けた(例: The Hillbilly)。表記を確かめるなら英語の公式ページ(https://deadbydaylight.com/)を開く。
- 一部のキャラ名は公式の日本語表記が長音・中点の違いで揺れる可能性がある(木村結衣は姓名の間に中点なし。公式サイトマップの表記どおり)。
- 公式の「難易度」表示は変わりうる。確認から 90 日で見直す対象。
- ページ内の 40 字以内の原文が、紹介文でなくパークの説明から取ったものがある: フェン・ミン(quote)、ジェーン(札)、結衣(quote)、デイビッド・キング(quote)。サバイバーは能力の説明がなく固有パークだけが型を示すため(設計書 3-3)。
- 公式の「ファンコンテンツ」の定義は「ゲームプレイ映像・アートワーク」で、キャラ名・文章の引用の扱いは書かれていない。利用規約は「コンテンツ(キャラクター名・テキストを含む)の再利用・複製・公開を禁じる」と書いているため、**公式の紹介文を引用する図鑑が規約に触れないかは文面から断定できない**。詳しくは policy-dbd.md。
