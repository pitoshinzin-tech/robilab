# PWA(ホーム画面に追加)段 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ロビラボを Android・iPhone・PC の Chrome / Edge で「ホーム画面に追加 / アプリとしてインストール」できるようにし(manifest・アイコン・iOS の meta・`viewport-fit=cover`)、電波がないときはロビラボの「オフラインです」の画面を出す最小の service worker と、`/my` と `/aim` の静かな「ホーム画面に追加」の案内を足す。

**Architecture:** manifest は `src/app/manifest.ts`(中身は `src/lib/pwa/manifest-data.ts` の `appManifest()`。テストから読めるように分ける)。アイコンの PNG は `scripts/app-icons.mjs` が 8×8 のドット絵の色の表から Node の `zlib` だけで書き出し、出力をコミットする(テストが「作り直し忘れ」を画素で見つける)。service worker は手書きの素の JS `public/sw.js`(ビルドを通さない)で、持つのは `offline.html` とアイコン 1 つだけ。どのリクエストを受け持つかは `shouldHandle(request, origin)` という純粋な関数にし、テストは `sw.js` の文をそのまま偽の `self`・`caches`・`fetch` で動かして確かめる。登録と `beforeinstallprompt` の受け取りは layout の `SwRegister`(何も描かない client 部品)で、判断は `src/lib/pwa/*.ts` の純粋な関数。案内のカードの「出すか・どの手順か」も純粋な関数(`install-hint.ts`)で、手順の文はサーバーで描いた要素を client 部品に渡す(文をブラウザの JS に入れない)。

**Tech Stack:** TypeScript / Next.js 16.3.6(App Router。manifest・`apple-icon` のファイル規約、`metadata.appleWebApp`、`viewport.viewportFit`、`next.config.ts` の `headers()`)/ React 19.2 / Tailwind CSS 4 / lucide-react / Vitest(environment node)/ Node 24(スクリプト。`zlib.crc32` を使う)。新しい道具は足さない。

**Spec:** `docs/superpowers/specs/2026-10-03-pwa-design.md`(以下「設計書」)。デザインの決まりは `docs/superpowers/plans/2026-10-02-ui-polish.md` の「Global Constraints」、JS の測り方は `docs/design/js-budget.md` と `scripts/page-js.mjs`、書き方の手本は `docs/superpowers/plans/2026-10-03-gear-finder.md`。ぶつかったときは、PWA の動き・安全は設計書、見た目の決まりは ui-polish の計画を正とする(この計画の「設計書との読み替え」で決めたものは、それが正)。

**読んだ Next.js の説明(16.3.6、`node_modules/next/dist/docs/`):** `01-app/02-guides/progressive-web-apps.md`(`/sw.js` の見出しの例・`updateViaCache: 'none'`)、`01-app/03-api-reference/03-file-conventions/01-metadata/manifest.md`(`manifest.ts` は既定でキャッシュされる特別なルートハンドラ・`MetadataRoute.Manifest`)、`.../01-metadata/app-icons.md`(`apple-icon` は `.jpg/.jpeg/.png` だけ・`app/**/*` に置くと `<link rel="apple-touch-icon">` が自動)、`01-app/03-api-reference/04-functions/generate-metadata.md`(`appleWebApp` は `mobile-web-app-capable`・`apple-mobile-web-app-title`・`apple-mobile-web-app-status-bar-style` を出す)、`.../05-config/01-next-config-js/headers.md`(同じパスに同じキーが 2 つ当たると後ろが勝つ)。型は `node_modules/next/dist/lib/metadata/types/manifest-types.d.ts`(`id`・`shortcuts`・`categories`・`purpose: 'any' | 'maskable' | 'monochrome'`)と `extra-types.d.ts`(`ViewportLayout.viewportFit`・`AppleWebApp`)。担当は、触る API の説明をもう一度読んでから書く(AGENTS.md)。

**ブランチと並んで動いている作業:** 実装は `feat/perf-floor` の上に新しく切る `feat/pwa`(Task 0 でコントローラーが切る)。別の担当が同時に `feat/perf-floor` で `src/app/layout.tsx`・`src/app/globals.css`・各ページの速さを直している。**`src/app/layout.tsx`・`next.config.ts`・`src/app/my/page.tsx`・`src/app/aim/page.tsx`・`src/app/aim/AimClient.tsx` を触るタスク(Task 4・5・7)は、必ずその時点のファイルを読み直してから、下に書いた「元の文」で探して置き換える(行番号では探さない)。** 元の文が見つからないとき(別の担当が書き換えた)は、同じ意味の所を探して同じ変更を当て、報告に「元の文が変わっていた・どこに当てたか」を書く。`globals.css` は触らない。

## Global Constraints

**設計書から(そのまま)**
- 新しいパッケージは足さない。Serwist などの PWA のライブラリ、`web-push` は使わない。PNG はスクリプトで Node の標準(`zlib`)だけ(sharp は使わない)。
- manifest:`id` `"/"`・`name` と `short_name` は `"ロビラボ"`(`BRAND.name`。英字は入れない)・`description` は `BRAND.description`・`start_url` `"/"`・`scope` `"/"`・`display` `"standalone"`・`orientation` は書かない・`background_color` と `theme_color` は `"#0A0C16"`(`BRAND.colors.bg`)・`lang` `"ja"`・`dir` `"ltr"`・`categories` `["games", "entertainment"]`・ショートカットは「今日の文字 `/aim`」「仲間 `/lobby`」「マウス探し `/mouse`」(アイコンは書かない)。文字を直書きせず `BRAND` から作る。
- アイコン:`public/icons/icon-192.png`(192・any)・`public/icons/icon-512.png`(512・any)・`public/icons/icon-maskable-512.png`(512・maskable、マークは中央の半径 205px の円の中)・`src/app/apple-icon.png`(180、透明なし、角は丸めない)。`src/app/icon.svg` は変えない。今は仮(今のファビコンのドット絵の「ロ」を、1 マスをそのまま大きくする。ぼかさない)。
- service worker は `public/sw.js`(手書きの素の JS、スコープ `/`)。`CACHE = "robilab-offline-v1"`。持つのは `/offline.html` と `/icons/icon-192.png` だけ。`fetch` で受け持つのは「`mode === "navigate"` かつ `GET`・同じ origin・`/auth/` で始まらない」だけ。応答は `preloadResponse` → `fetch`、失敗のときだけ `offline.html`。**`cache.put` を書かない。`message`・`push`・`sync`・`importScripts` を書かない。**
- 登録は本番のビルドのときだけ、`load` のあとに `navigator.serviceWorker.register("/sw.js", { scope: "/", updateViaCache: "none" })`。`serviceWorker` がなければ何もしない。失敗しても画面に何も出さない。
- `/sw.js` の見出し:`Cache-Control: no-cache, no-store, must-revalidate`・`Content-Security-Policy: default-src 'self'; script-src 'self'`・`Content-Type: application/javascript; charset=utf-8`。全体の CSP に `worker-src 'self'` と `manifest-src 'self'`(`blob:` は許さない)。`Service-Worker-Allowed` は付けない。**`src/proxy.ts` の matcher は変えない**(`/sw.js` などは Supabase のセッション更新を通さないまま)。
- layout:`metadata.appleWebApp = { capable: true, title: "ロビラボ", statusBarStyle: "black" }`・`viewport.viewportFit = "cover"`・`metadata.manifest` は書かない。
- 案内:ページを開いた瞬間のポップアップ・下からの帯は作らない。`/my` の段(閉じるなし、アプリ表示では出さない)と `/aim` の「あなたの記録」の下のカード(2 日目から最大 3 日、× で二度と出さない、インストールしたら二度と出さない)。トップ(`/`)には出さない。記録は `localStorage` の `robilab:pwaHint` = `{ v: 1, days: [...最大 4], dismissed }` だけ(サーバーに送らない。読み書きの失敗のときは出さない)。`beforeinstallprompt` は使えるときだけ「追加する」、`preventDefault()` はしない。手順の文はサーバーで HTML に入れ、`<details>`「追加のしかた」で開く。絵文字は使わない(lucide の `Share`・`SquarePlus` など)。動きはなし。base-ui は使わない。
- オフラインの画面 `public/offline.html`:JS なし・外のフォント / CSS なし・CSS は中に書く・背景 #0A0C16・文字 #EAF6FF・押せるものだけシアン #39F3FF・ドット絵の「ロ」の SVG を中に・文「電波が届いていません」「つながったら、もう一度読み込んでください。」・ボタン「もう一度読み込む」は `<a href="/">`・システムの書体・44px 以上・フォーカスの線・コントラスト 4.5:1 以上。
- JS は 1 ページ 4KB(gzip)以内の増え。スマホの LCP を悪くしない。差分のセキュリティ監査で confirmed の critical / high が 0。
- プッシュ通知・オフラインでページの中身を見せること・ストア版・iOS の起動画面・manifest の screenshots は作らない。

**ui-polish の Global Constraints から(そのまま。この計画に関係する分)**

## Review Focus

1. **共有の端末で、個人のページ・ログインの応答・古いページがキャッシュに残る**(ログインして `/lobby`・`/my` を開いたあと、次の人がオフラインで開く・古い版が出る)。期待:キャッシュにあるのは `robilab-offline-v1` の 2 ファイルだけで、何を開いても増えない。→ Task 2 のテスト(ネットの応答を保存しない・`caches.open` を fetch の中で呼ばない・文に `.put(` がない・install で入れるのはちょうど 2 つ)と、Task 8 のブラウザ確認(`/lobby` `/my` `/aim` `/mouse` を開いたあとの Cache Storage の一覧)。
2. **service worker がログインの往復・送信・外の通信に割り込む**:`/auth/callback?code=…`、`/auth` そのもの、server actions の POST、Supabase(別の origin)の通信、画像・JS(`mode` が `no-cors` / `cors`)、壊れた URL。期待:どれにも `respondWith` しない(ブラウザにそのまま任せる)。`/authors` のような「`/auth` で始まるが別の道」は受け持つ。→ Task 2 の `shouldHandle` のテストと fetch のテスト(`respondWith` が呼ばれない)、Task 8 のオフラインの確認(`/auth/callback` はオフラインの画面にならない)。
3. **`robilab:pwaHint` が壊れている・読めない・日付がずれる**:壊れた JSON・`null`・`v` が違う・`days` が文字・5 件以上・重なり・プライベートモードで `localStorage` が投げる・JST の 0 時をまたぐ・端末の時計を戻した。期待:落ちない、読めないときは出さない、0 時(JST)で日が変わる、表示は最大 3 日。→ Task 6 のテスト(`parseHintState`・`hintView`・`jstToday`)と Task 7 の `openHintStorage` のテスト。
4. **端末の取り違え**:iPadOS(Mac の顔+タッチ点)、iPhone の Chrome(`CriOS`)、Android の Firefox、PC の Safari・Firefox(インストールできない)、PC の Edge、アプリ表示で開いた。期待:iPad も iPhone の手順、PC の Safari・Firefox は `/aim` に出さず `/my` は「このブラウザでは…」、アプリ表示ではどこにも出さない。→ Task 6 の `detectPlatform` の表のテスト。
5. **開発中に service worker が登録されて画面が古いまま・更新が届かない**:`next dev` で登録される、`/sw.js` がブラウザや CDN にキャッシュされる。期待:本番のビルドだけ登録、`updateViaCache: "none"`、`/sw.js` は `no-store`。→ Task 5 の `scheduleSwRegister` のテスト(`development`・`test` で登録しない・登録の引数)と Task 4 のテスト(`/sw.js` の見出し、全体のルールより後ろ)、Task 8 の `curl -I`。

## 設計書との読み替え(実装の都合で決めたこと)

1. **「追加する」は `variant="secondary"`**(設計書は「主ボタン」)。`/aim`(遊ぶ面・結果)と `/my`(エディター)にはすでに `primary` があり、「主ボタンは 1 画面に 1 つ」の決まりを守るため。
2. **`/my` の段は箱なし**(`SectionHeading`+本文。Card のルール)。**`/aim` は設計書どおり 1 枚の `Card`**(閉じる × つき)。
3. **端末が「other」(PC の Safari・Firefox など)のとき**:`/aim` のカードは出さない。`/my` の段は出し、手順の代わりに「このブラウザでは追加できないことがあります。iPhone は Safari、Android と PC は Chrome か Edge で開くと追加できます。」を出す。
4. **`beforeinstallprompt` と `appinstalled` は layout の `SwRegister` で受け取り始め、`src/lib/pwa/install-prompt.ts` のモジュールの中に持つ**(`useSyncExternalStore` で読む)。理由:知らせはページを開いた直後に 1 回だけ来るので、`/aim` の下のほうのカードが後から出ても、トップから `/aim` に移っても使えるように。`prompt()` は 1 回しか使えないので、使ったら手放す。
5. **今日の日付(JST)は `/aim` のサーバーから渡す**(`page.tsx` がすでに持つ `date`)。client の描画中に `new Date()` を呼ばない(lint と、サーバーとずれないため)。`/my` は来訪を数えない(数えるのは `/aim` だけ)。`jstToday(now)` は `install-hint.ts` に置き(`@/lib/aim/daily` を client に入れないため。式は `jstDate` と同じで、テストで同じ答えを確かめる)。
6. **manifest の中身は `src/lib/pwa/manifest-data.ts` の `appManifest()`、head の値は `src/lib/pwa/head.ts`(`APPLE_WEB_APP`・`SITE_VIEWPORT`)**。`src/app/manifest.ts` と layout はそれを使うだけ(テストが `next/font` を読まずに値を確かめられるように)。layout の `themeColor` の直書き `"#0A0C16"` は `BRAND.colors.bg` になる(値は同じ)。
7. **`sw.js` のテストは、ファイルの文をそのまま `new Function("self", "caches", "fetch", …)` で動かす**(ビルドしない・写しを作らない)。受け持つかの判断は `shouldHandle(request, origin)` の純粋な関数として、同じ文の中から取り出してテストする。
8. **「`/auth/` で始まらない」は `/auth` そのものも含めて触らない**(`pathname === "/auth" || pathname.startsWith("/auth/")`)。`/authors` のような別の道は受け持つ。
9. **「自分のキャッシュ」= 名前が `robilab-` で始まるもの**。`activate` で `CACHE` 以外の `robilab-*` だけ消す(同じ origin のほかのキャッシュは触らない)。キャッシュにも無いときは `Response.error()`(ブラウザのいつもの画面)。
10. **アイコンの並べ方**:8×8 のマスを整数の大きさで中央に置き、外は背景色で埋める。192 = 1 マス 24px(余りなし)、512(any)= 64px、maskable 512 = 48px(格子 384px を中央に。描いてある点のいちばん遠い所は中心から約 173px で、半径 205px の円の中)、180 = 22px(格子 176px、上下左右に 2px の余り)。PNG は RGB 8bit(透明の通り道を持たない)。比べのテストは「画素」で行う(Node の zlib の版で圧縮の結果が変わっても通る)。
11. **`export/app-icon/` も同じスクリプトで書き出す**(`app-icon.svg`・`icon-192.png`・`icon-512.png`・`icon-maskable-512.png`・`apple-icon-180.png`)。社長のロゴが「ドット絵でない」ときは `ICON_SOURCE` を `"photoshop"` にして、画素の比べのテストを止める(大きさのテストは残る)。
12. **オフラインの画面のボタンの高さは 48px**(44px 以上で 8 の倍数)。`<meta name="robots" content="noindex">` を付ける。
13. **ブラウザ確認の「Network を Offline に」は、サーバーを止めて代える**(ブラウザの道具から回線を切れないため。つながらない = `fetch` の失敗で同じ道を通る)。Lighthouse の本物の計測は社長の確認リストへ。Claude は LCP を ui-polish Task 19 の計測の JS で前後比べる。
14. **`/aim` のカードは `AimClient` の `installHint` の差し込み口に入れる**(`AimHistory` の直後。`AimHistory` と同じく、ハイドレーションのあと・最初の画面の外に出るので CLS を起こさない)。

```js
// アプリのアイコン(PWA・iPhone)を、8×8 のドット絵の色の表から作る。Node の標準(zlib)だけ(パッケージを足さない)。
// 使い方: node scripts/app-icons.mjs
// 絵は src/app/icon.svg(タブのアイコン)と同じ。社長のロゴができたら GRID と COLORS を差し替えて作り直す(docs/ops/launch.md)。
// ドット絵でないロゴを Photoshop で書き出して置き換えたときは ICON_SOURCE を "photoshop" にする(画素の比べのテストが止まる)。
import fs from "node:fs";
import path from "node:path";
import zlib from "node:zlib";
import { fileURLToPath } from "node:url";

/** "grid" = このスクリプトの GRID から作る / "photoshop" = 社長が書き出した PNG を置いた */
export const ICON_SOURCE = "grid";

export const COLORS = { ".": "#0A0C16", M: "#FF4FD8", P: "#A99BFF" };
export const BG = COLORS["."];
export const GRID = [
  "........",
  "..MMMM..",
  ".M....M.",
  ".M.PP.M.",
  ".M.PP.M.",
  ".M....M.",
  "..MMMM..",
  "........",
];

/** maskable のアイコンで、マークを収める円の半径(512 の中央 80%) */
export const MASKABLE_SAFE_RADIUS = 205;

/** out = サイトで使う場所、copy = Photoshop 用の写し、cell = 1 マスの px(整数。ぼかさない) */
export const ICONS = [
  { out: "public/icons/icon-192.png", copy: "export/app-icon/icon-192.png", size: 192, cell: 24 },
  { out: "public/icons/icon-512.png", copy: "export/app-icon/icon-512.png", size: 512, cell: 64 },
  { out: "public/icons/icon-maskable-512.png", copy: "export/app-icon/icon-maskable-512.png", size: 512, cell: 48 },
  { out: "src/app/apple-icon.png", copy: "export/app-icon/apple-icon-180.png", size: 180, cell: 22 },
];

export const SVG_OUT = "export/app-icon/app-icon.svg";

const SIG = Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]);

function rgbOf(color) {
  return [1, 3, 5].map((i) => parseInt(color.slice(i, i + 2), 16));
}

/** 8×8 の格子を 1 マス cell px で中央に置き、外は背景色。RGB(1 画素 3 バイト)を返す */
export function renderPixels(size, cell) {
  const offset = Math.floor((size - cell * 8) / 2);
  const rgb = Buffer.alloc(size * size * 3);
  for (let y = 0; y < size; y++) {
    for (let x = 0; x < size; x++) {
      const gx = Math.floor((x - offset) / cell);
      const gy = Math.floor((y - offset) / cell);
      const inside = x >= offset && y >= offset && gx < 8 && gy < 8;
      const [r, g, b] = rgbOf(COLORS[inside ? GRID[gy][gx] : "."]);
      const i = (y * size + x) * 3;
      rgb[i] = r;
      rgb[i + 1] = g;
      rgb[i + 2] = b;
    }
  }
  return rgb;
}

function chunk(type, data) {
  const len = Buffer.alloc(4);
  len.writeUInt32BE(data.length);
  const body = Buffer.concat([Buffer.from(type, "ascii"), data]);
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(zlib.crc32(body));
  return Buffer.concat([len, body, crc]);
}

/** 8bit・RGB(color type 2)・フィルター 0 の PNG */
export function encodePng(width, height, rgb) {
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(width, 0);
  ihdr.writeUInt32BE(height, 4);
  ihdr[8] = 8; // ビットの深さ
  ihdr[9] = 2; // RGB(透明なし)
  const stride = width * 3;
  const raw = Buffer.alloc((stride + 1) * height);
  for (let y = 0; y < height; y++) rgb.copy(raw, y * (stride + 1) + 1, y * stride, (y + 1) * stride);
  return Buffer.concat([SIG, chunk("IHDR", ihdr), chunk("IDAT", zlib.deflateSync(raw, { level: 9 })), chunk("IEND", Buffer.alloc(0))]);
}

/** 大きさと color type はどの PNG でも読む。画素(rgb)は encodePng と同じ形(RGB・フィルター 0)のときだけ */
export function decodePng(buf) {
  if (!buf.subarray(0, 8).equals(SIG)) throw new Error("PNG ではありません");
  let pos = 8;
  let width = 0;
  let height = 0;
  let colorType = -1;
  const idat = [];
  while (pos < buf.length) {
    const len = buf.readUInt32BE(pos);
    const type = buf.toString("ascii", pos + 4, pos + 8);
    const data = buf.subarray(pos + 8, pos + 8 + len);
    if (type === "IHDR") {
      width = data.readUInt32BE(0);
      height = data.readUInt32BE(4);
      colorType = data[9];
    } else if (type === "IDAT") idat.push(data);
    else if (type === "IEND") break;
    pos += 12 + len;
  }
  let rgb = Buffer.alloc(0);
  if (colorType === 2) {
    const raw = zlib.inflateSync(Buffer.concat(idat));
    const stride = width * 3;
    rgb = Buffer.alloc(stride * height);
    for (let y = 0; y < height; y++) {
      if (raw[y * (stride + 1)] !== 0) throw new Error("フィルター 0 の PNG だけ画素を読めます");
      raw.copy(rgb, y * stride, y * (stride + 1) + 1, (y + 1) * (stride + 1));
    }
  }
  return { width, height, colorType, rgb };
}

/** Illustrator 用(仕上がり 512×512、1 マス 64px)。レイヤー = 01_background・02_mark・guide_maskable_safe_zone(非表示) */
export function renderSvg() {
  const cell = 64;
  const groups = new Map();
  GRID.forEach((row, y) => {
    [...row].forEach((key, x) => {
      if (key === ".") return;
      const color = COLORS[key];
      if (!groups.has(color)) groups.set(color, []);
      groups.get(color).push(`    <rect x="${x * cell}" y="${y * cell}" width="${cell}" height="${cell}"/>`);
    });
  });
  const mark = [...groups].map(([color, rects]) => `   <g fill="${color}">\n${rects.join("\n")}\n   </g>`).join("\n");
  return [
    '<svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512" shape-rendering="crispEdges">',
    "  <title>ロビラボ アプリのアイコン(仮。ドット絵の「ロ」)</title>",
    '  <g id="01_background">',
    `    <rect width="512" height="512" fill="${BG}"/>`,
    "  </g>",
    '  <g id="02_mark">',
    mark,
    "  </g>",
    '  <g id="guide_maskable_safe_zone" display="none">',
    `    <circle cx="256" cy="256" r="${MASKABLE_SAFE_RADIUS}" fill="none" stroke="#39F3FF" stroke-width="2"/>`,
    "  </g>",
    "</svg>",
    "",
  ].join("\n");
}

function main() {
  for (const icon of ICONS) {
    const png = encodePng(icon.size, icon.size, renderPixels(icon.size, icon.cell));
    for (const file of [icon.out, icon.copy]) {
      fs.mkdirSync(path.dirname(file), { recursive: true });
      fs.writeFileSync(file, png);
      console.log(`${file}\t${icon.size}×${icon.size}\t${png.length} bytes`);
    }
  }
  fs.mkdirSync(path.dirname(SVG_OUT), { recursive: true });
  fs.writeFileSync(SVG_OUT, renderSvg());
  console.log(SVG_OUT);
}

if (process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)) main();
```

```ts
  const stores = new Map<string, Store>();
```

```js
/* global self, caches */
/*
 * ロビラボの service worker(PWA 段 1)。持つのはオフラインの画面とアイコン 1 つだけ。ページ・データは保存しない。
 * 設計書:docs/superpowers/specs/2026-10-03-pwa-design.md 3 章。止め方:docs/ops/launch.md「service worker を止めるとき」。
 * offline.html かアイコンを変えたら CACHE の数字を上げる。cache.put・message・push・sync・importScripts は書かない
 * (段 2 のプッシュ通知を足すときも、このファイルに足す。スコープ / の service worker は 1 つだけ)。
 */
const CACHE = "robilab-offline-v1";
const OFFLINE_URL = "/offline.html";
const PRECACHE = [OFFLINE_URL, "/icons/icon-192.png"];

/** 受け持つのは「同じ origin のページを開く GET」で、ログインの往復(/auth)以外だけ。ほかはブラウザに任せる */
function shouldHandle(request, origin) {
  if (request.mode !== "navigate" || request.method !== "GET") return false;
  let url;
  try {
    url = new URL(request.url);
  } catch {
    return false;
  }
  if (url.origin !== origin) return false;
  return !(url.pathname === "/auth" || url.pathname.startsWith("/auth/"));
}

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches
      .open(CACHE)
      .then((cache) => cache.addAll(PRECACHE))
      .then(() => self.skipWaiting()),
  );
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    (async () => {
      const keys = await caches.keys();
      await Promise.all(keys.filter((key) => key.startsWith("robilab-") && key !== CACHE).map((key) => caches.delete(key)));
      // service worker の起動を待つ間に、ページの通信を先に始める(開くのが遅くならないように)
      if (self.registration.navigationPreload) await self.registration.navigationPreload.enable();
      await self.clients.claim();
    })(),
  );
});

self.addEventListener("fetch", (event) => {
  if (!shouldHandle(event.request, self.location.origin)) return;
  event.respondWith(
    (async () => {
      try {
        const preloaded = await event.preloadResponse;
        if (preloaded) return preloaded;
        return await fetch(event.request);
      } catch {
        // ネットにつながらないときだけ。成功した応答は保存しない
        const offline = await caches.match(OFFLINE_URL);
        return offline || Response.error();
      }
    })(),
  );
});
```

```ts
export const SW_URL = "/sw.js";

export type SwRegisterEnv = {
  nodeEnv: string | undefined;
  serviceWorker: { register(url: string, options: RegistrationOptions): Promise<unknown> } | undefined;
  readyState: DocumentReadyState;
  /** load の耳を付け、外す関数を返す */
  addLoadListener: (fn: () => void) => () => void;
};

/**
 * 本番のビルドで service worker が使えるときだけ、ページの読み込みのあとに /sw.js を登録する(設計書 3-2)。
 * updateViaCache: "none" で、ページを開くたびにブラウザが新しい sw.js を確かめる。失敗しても何も出さない。戻り値は後片付け。
 */
export function scheduleSwRegister(env: SwRegisterEnv): () => void {
  const sw = env.serviceWorker;
  if (env.nodeEnv !== "production" || !sw) return () => {};
  const go = () => {
    sw.register(SW_URL, { scope: "/", updateViaCache: "none" }).catch(() => {});
  };
  if (env.readyState === "complete") {
    go();
    return () => {};
  }
  return env.addLoadListener(go);
}
```

`src/lib/pwa/install-prompt.ts`:

```ts
/** Chrome・Edge の beforeinstallprompt(標準の型にないので、使う所だけ) */
export type InstallPromptEvent = Event & { prompt: () => Promise<unknown> };
export type InstallPromptSnapshot = { event: InstallPromptEvent | null; installed: boolean };
type Target = Pick<EventTarget, "addEventListener">;

export type InstallPromptStore = {
  start(target: Target): void;
  prompt(): Promise<void>;
  subscribe(fn: () => void): () => void;
  get(): InstallPromptSnapshot;
};

/** useSyncExternalStore のサーバーの値(同じものを返し続ける) */
export const SERVER_SNAPSHOT: InstallPromptSnapshot = { event: null, installed: false };

/**
 * 「ホーム画面に追加」の知らせを持つ入れ物(読み替え 4)。知らせはページを開いた直後に 1 回だけ来るので、
 * layout の SwRegister で受け取り始め、ページを移っても使えるようにモジュールの中に持つ。
 * preventDefault はしない(ブラウザ自身の案内を消さない。設計書 4-2)。
 */
export function createInstallPromptStore(): InstallPromptStore {
  let snapshot: InstallPromptSnapshot = SERVER_SNAPSHOT;
  let started = false;
  const listeners = new Set<() => void>();
  const set = (next: InstallPromptSnapshot) => {
    snapshot = next;
    listeners.forEach((fn) => fn());
  };
  return {
    start(target) {
      if (started) return;
      started = true;
      target.addEventListener("beforeinstallprompt", (e) => set({ ...snapshot, event: e as InstallPromptEvent }));
      target.addEventListener("appinstalled", () => set({ event: null, installed: true }));
    },
    async prompt() {
      const e = snapshot.event;
      if (!e) return;
      // prompt() は 1 回しか使えないので、先に手放す(ボタンが消える)
      set({ ...snapshot, event: null });
      try {
        await e.prompt();
      } catch {
        // 使えないときは何もしない(手順の文は残っている)
      }
    },
    subscribe(fn) {
      listeners.add(fn);
      return () => {
        listeners.delete(fn);
      };
    },
    get: () => snapshot,
  };
}

export const installPromptStore = createInstallPromptStore();
```

```ts
// 「ホーム画面に追加」の案内を出すか・どの手順を見せるか(設計書 4 章)。ブラウザに触らない純粋な関数だけ。
// 記録はこの端末の localStorage だけ(日付と真偽。個人の情報は入れない・サーバーに送らない)。

export type HintPlatform = "ios" | "android" | "desktop" | "other" | "installed";
export type StepsPlatform = Exclude<HintPlatform, "installed">;
export type HintPlace = "my" | "aim";
export type HintState = { v: 1; days: string[]; dismissed: boolean };

export const HINT_STORAGE_KEY = "robilab:pwaHint";
/** 記録する来訪日の数(1 日目 + 案内を出す 3 日) */
export const HINT_MAX_DAYS = 4;
export const EMPTY_HINT: HintState = { v: 1, days: [], dismissed: false };

const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;

/** JST の今日(YYYY-MM-DD)。式は今日の文字の jstDate と同じ(@/lib/aim/daily をブラウザに入れないため、ここに持つ) */
export function jstToday(now: Date): string {
  return new Date(now.getTime() + 9 * 3600 * 1000).toISOString().slice(0, 10);
}

/** iPadOS は Mac の顔をするので、タッチの点の数でも見る。PC の Safari・Firefox は「other」(インストールの道が違う・無い) */
export function detectPlatform(input: { userAgent: string; maxTouchPoints: number; standalone: boolean }): HintPlatform {
  if (input.standalone) return "installed";
  const ua = input.userAgent;
  if (/iPhone|iPad|iPod/.test(ua) || (/Macintosh/.test(ua) && input.maxTouchPoints > 1)) return "ios";
  if (/Android/.test(ua)) return "android";
  if (/(Chrome|Chromium|Edg)\//.test(ua)) return "desktop";
  return "other";
}

/** 読めない値は空にする。日付でない要素・重なりは捨て、最初の 4 件だけ */
export function parseHintState(raw: string | null): HintState {
  if (!raw) return EMPTY_HINT;
  let data: unknown;
  try {
    data = JSON.parse(raw);
  } catch {
    return EMPTY_HINT;
  }
  if (typeof data !== "object" || data === null || Array.isArray(data)) return EMPTY_HINT;
  const o = data as { v?: unknown; days?: unknown; dismissed?: unknown };
  if (o.v !== 1 || !Array.isArray(o.days)) return EMPTY_HINT;
  const days: string[] = [];
  for (const d of o.days) {
    if (typeof d === "string" && DATE_RE.test(d) && !days.includes(d)) days.push(d);
    if (days.length >= HINT_MAX_DAYS) break;
  }
  return { v: 1, days, dismissed: o.dismissed === true };
}

/** 今日を来訪日に足す。閉じた・今日は記録済み・4 件そろっている、のときは同じオブジェクトを返す */
export function nextHintState(state: HintState, today: string): HintState {
  if (state.dismissed || state.days.includes(today) || state.days.length >= HINT_MAX_DAYS) return state;
  return { ...state, days: [...state.days, today] };
}

export function dismissHint(state: HintState): HintState {
  return state.dismissed ? state : { ...state, dismissed: true };
}

/** /aim のカード:2 日目から最大 3 日(今日が来訪日の 2〜4 番目)。閉じたら出さない。追加できる端末だけ */
export function shouldShowHint(state: HintState, today: string, platform: HintPlatform): boolean {
  if (state.dismissed || platform === "installed" || platform === "other") return false;
  const i = state.days.indexOf(today);
  return i >= 1 && i <= HINT_MAX_DAYS - 1;
}

/**
 * 1 回の表示で出すか・保存し直す状態。stored が undefined = localStorage が使えない(出さない)。
 * /my はアプリ表示以外のいつでも出し、来訪を数えない。/aim は today(サーバーの JST の日付)が要る。
 */
export function hintView(input: { place: HintPlace; platform: HintPlatform; stored: string | null | undefined; today?: string }): {
  show: boolean;
  platform: HintPlatform;
  next: HintState | null;
} {
  const { place, platform, stored, today } = input;
  if (place === "my") return { show: platform !== "installed", platform, next: null };
  if (stored === undefined || !today) return { show: false, platform, next: null };
  const state = parseHintState(stored);
  if (platform === "installed") {
    const dismissed = dismissHint(state);
    return { show: false, platform, next: dismissed === state ? null : dismissed };
  }
  const next = nextHintState(state, today);
  return { show: shouldShowHint(next, today, platform), platform, next: next === state ? null : next };
}
```

注意:`parseHintState(null)` などで返す `EMPTY_HINT` は 1 つのオブジェクトを使い回す。`nextHintState` は新しいオブジェクトを作って返すので、`EMPTY_HINT` を書き換えることはない(書き換える関数を足さない)。

```tsx
"use client";
import { useEffect, useMemo, useState, useSyncExternalStore, type ReactNode } from "react";
import { Download, X } from "lucide-react";
import { useIsClient } from "@/lib/use-is-client";
import { installPromptStore, SERVER_SNAPSHOT } from "@/lib/pwa/install-prompt";
import { HINT_STORAGE_KEY, detectPlatform, dismissHint, hintView, parseHintState, type HintPlace, type StepsPlatform } from "@/lib/pwa/install-hint";
import { Card } from "@/components/ui/card";
import { PlainButton } from "@/components/ui/plain-button";
import { SectionHeading } from "@/components/ui/section-heading";
import { cn } from "@/lib/utils";

type HintStorage = Pick<Storage, "getItem" | "setItem">;

/** localStorage が使えれば返す。プライベートモードなどで読めない・書けないときは null(案内を出さない) */
export function openHintStorage(): HintStorage | null {
  try {
    const s = window.localStorage;
    const probe = "robilab:probe";
    s.setItem(probe, "1");
    s.removeItem(probe);
    return s;
  } catch {
    return null;
  }
}

function save(storage: HintStorage | null, value: unknown) {
  if (!storage) return;
  try {
    storage.setItem(HINT_STORAGE_KEY, JSON.stringify(value));
  } catch {
    // 書けなくても画面は変えない
  }
}

function readStored(storage: HintStorage | null): string | null | undefined {
  if (!storage) return undefined;
  try {
    return storage.getItem(HINT_STORAGE_KEY);
  } catch {
    return undefined;
  }
}

/** ブラウザでだけ呼ぶ(useIsClient が true のとき) */
function readEnv(place: HintPlace, today: string | undefined) {
  const standalone = window.matchMedia?.("(display-mode: standalone)").matches === true || (navigator as Navigator & { standalone?: boolean }).standalone === true;
  const platform = detectPlatform({ userAgent: navigator.userAgent, maxTouchPoints: navigator.maxTouchPoints ?? 0, standalone });
  const storage = place === "aim" ? openHintStorage() : null;
  return { storage, view: hintView({ place, platform, stored: place === "aim" ? readStored(storage) : null, today }) };
}

const LEAD: Record<HintPlace, string> = {
  aim: "アイコンから、毎日の今日の文字にワンタップで。",
  my: "アプリのように全画面で開けます。",
};

/**
 * 「ホーム画面に追加」の静かな案内(設計書 4 章)。手順の文はサーバーで描いた steps を受け取り、JS が決めるのは
 * 「出すか」「どの手順か」「追加する(prompt)」だけ。ハイドレーションのあとに出す(置き場所はどちらも最初の画面の外)。
 */
export function InstallHint({ place, today, steps, className }: { place: HintPlace; today?: string; steps: Record<StepsPlatform, ReactNode>; className?: string }) {
  const isClient = useIsClient();
  const prompt = useSyncExternalStore(installPromptStore.subscribe, installPromptStore.get, () => SERVER_SNAPSHOT);
  const [closed, setClosed] = useState(false);
  const env = useMemo(() => (isClient ? readEnv(place, today) : null), [isClient, place, today]);

  // 来訪日の記録(/aim だけ)。effect では保存だけして、setState はしない
  useEffect(() => {
    if (env?.view.next) save(env.storage, env.view.next);
  }, [env]);
  // インストールしたら二度と出さない
  useEffect(() => {
    if (prompt.installed && env?.storage) save(env.storage, dismissHint(parseHintState(readStored(env.storage) ?? null)));
  }, [prompt.installed, env]);

  if (!env || !env.view.show || closed || prompt.installed || env.view.platform === "installed") return null;
  const platform = env.view.platform;
  const canPrompt = prompt.event !== null && (platform === "android" || platform === "desktop");

  const body = (
    <div className="grid gap-4">
      <p className="text-sm text-rl-muted">{LEAD[place]}</p>
      {canPrompt && (
        <div>
          <PlainButton variant="secondary" size="sm" onClick={() => void installPromptStore.prompt()}>
            <Download aria-hidden />
            追加する
          </PlainButton>
        </div>
      )}
      {platform === "other" ? (
        steps.other
      ) : (
        <details className="group">
          <summary className="inline-flex min-h-11 cursor-pointer items-center text-sm font-bold text-rl-accent underline-offset-4 hover:underline">追加のしかた</summary>
          <div className="pt-2">{steps[platform]}</div>
        </details>
      )}
    </div>
  );

  if (place === "my") {
    return (
      <section aria-labelledby="install-hint-heading" className={cn("grid gap-4", className)}>
        <SectionHeading id="install-hint-heading" title="ホーム画面に追加" />
        {body}
      </section>
    );
  }

  const close = () => {
    save(env.storage, dismissHint(parseHintState(readStored(env.storage) ?? null)));
    setClosed(true);
  };
  return (
    <Card as="section" aria-labelledby="install-hint-heading" className={cn("grid gap-4", className)}>
      <div className="flex items-start justify-between gap-4">
        <h2 id="install-hint-heading" className="min-w-0 text-xl font-bold">ホーム画面に追加</h2>
        <PlainButton variant="ghost" size="icon" aria-label="閉じる" onClick={close} className="-mr-2 -mt-2">
          <X aria-hidden />
        </PlainButton>
      </div>
      {body}
    </Card>
  );
}
```
