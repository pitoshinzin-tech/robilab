# デバイスの広がり(マウス 54・マウスパッド・ソール)— 設計書

- 日付:2026-10-03
- 状態:社長の「じゃんじゃん進めて」を受け、CEO が決めた設計。社長はいつでも変えられる
- 前提:plan.md の D41(マウス探し)、D44・D45(UI の見直し・アートディレクション)、`docs/superpowers/specs/2026-10-02-ui-polish-design.md` と `...-art-direction.md`
- データ:`docs/content/gear/mice.json`(54)、`pads.json`(48)、`skates.json`(58)と各 `*-notes.md`。どれもメーカー公式の数字だけで、出典 URL と確認日つき。公式にない数字は null

## 1. 目的と成功の基準

- 目的:マウス・マウスパッド・マウスソールを、それぞれ人気の上位 50 くらいまで、作り話なしの公式の数字で比べられるようにする(社長の要望、2026-10-03)。収益の入口(アフィリエイト、PR 表記つき)を広げる。
- 成功の基準
  - `/mouse` で 54 機種から、手に合う順に選べる(公式の大きさがない機種は「比べられません」と出し、順位に入れない)。
  - `/pads` で、面の種類・大きさ・厚さ・硬さで絞り込み、公式の言葉のまま「速さ・止め」の説明が読める。
  - `/skates` で、自分のマウス(マイ設定の登録 or その場で選ぶ)に合うソールが一覧できる。
  - どの画面も、作った数字を出さない。生産終了は札で分かる。

## 2. データ

- `src/data/mice.ts` を 54 件に広げる。型を少しだけ広げる:`shape` は `"symmetric" | "right" | null`、`connection` は `"wired" | "wireless" | "both"`、寸法・重さは `number | null`(null の理由は `note` に)。`devices.ts` の名前もそろえる。
- 新しく `src/data/pads.ts`(型 `PadSpec`)と `src/data/skates.ts`(型 `SkateSpec`)。JSON の中身をそのまま型付きで持つ(出典 URL・確認日・選んだ根拠・note も)。全部 null の 7 件のパッドは `hidden: true` で持つが出さない。生産終了は `discontinued: true`。
- テスト:id が重ならない、公式 URL が https、確認日が日付、ソールの `mouseIds` が `devices.ts` にある、null の数字を画面の計算に使わない、など。
- LGG のパッドは Pulsar の後継(Pulsar eS)として名前を直す(id は残す)。SkyPAD は Wallhack の名前で出す。

## 3. 画面

### 3-1. `/mouse`(広げる)
- 今の画面のまま 54 機種に。寸法がない機種は合う順の一覧の下に「公式の大きさがないため比べられません」の段でまとめる(店へのリンクは出す)。
- 形状が null の機種は「形:公式の記載なし」。接続 `both` は「有線・無線」。

### 3-2. `/pads`(新)
- 上:h1「マウスパッド探し」、数字の見せ場(例「42 枚」)、1 行の説明。
- 絞り込み(base-ui なしの `ChipButton`):面(布/ハイブリッド/ガラス/ハード)、大きさ(机の幅に合わせて S〜XXL の目安。公式の幅・奥行きから決める)、厚さ(薄い・ふつう・厚い。公式の厚さがあるものだけ)、硬さの種類があるもの。
- 一覧:1 行に 1 製品。メーカー・名前・面・サイズの表(公式の幅×奥行×厚さ)・公式の「速さ/止め」の言葉(引用の形で、出典つき)・硬さの種類・Amazon/楽天(PR)・公式ページ。生産終了は札。
- 並び:人気の順(`selectionBasis` の順位から作る。順位の根拠はページ下に一行で)。
- 空・絞り込み 0 件の状態、375px で崩れない。

### 3-3. `/skates`(新)
- 上:h1「マウスソール探し」、「マウスを選ぶ」(マイ設定に登録したマウスがあれば最初から選ぶ)。
- 一覧:選んだマウスに合うソール。ブランド・名前・素材(公式の言葉)・形(全面/ドット)・厚さ(公式に 1 つの数字があるときだけ。幅の表記は原文のまま)・枚数/セット数・Amazon/楽天(PR)・公式ページ。
- マウスを選んでいないときは、ブランド別の一覧と「マウスを選ぶと絞り込めます」。
- 絞り込み:素材・形。

### 3-4. ナビ
- 下のタブ「マウス」と PC のヘッダーの「マウス」から入る。各画面の上に `SubNav`「マウス探し・マウスパッド・ソール」。
- マウス探しの結果のカードから「このマウスのソール」へ(`/skates?mouse=<id>`)。

## 4. 守ること
- 数字はメーカー公式だけ。null は空欄・「公式の記載なし」。速さ・止めを点数にしない。価格は載せない。
- PR 表記、`rel="sponsored noopener"`、Amazon のタグ、楽天は検索リンク(新しい API の呼び出しはしない)。
- デザインシステム(役割の色、主ボタン 1 つ、44px、フォーカス、reduced-motion、文字の段、`cn` は `@/lib/utils`、base-ui を使わない軽い部品)と、アートディレクション(線とマス)。自動の動きは足さない。
- JS は 1 ページ 4KB 以内の増え。データはサーバーで絞り、ブラウザへは表示に要る分だけ送る。
- 出来上がったら、ほかの画面と同じ採点(375/1440 の写真、合格 8.2 以上)と、差分のセキュリティ監査。
