## 1. 目的と成功の基準

**目的**
- マイ設定の手の大きさと持ち方から、合うマウスを理由付きで出す。
- 収益の主軸(アフィリエイト)への入口にする。ただし中立に、公式ページも並べる。

**成功の基準**
- マイ設定の手の情報がそろっている人は、`/mouse` を開くだけで、合う順のマウスと理由が見られる。
- 手の情報がない人も、その場で入力すれば結果が出て、入力はマイ設定に残る。
- 今のマウス(マイ設定に登録したもの)と比べた差が出る。
- 「私に合うマウス TOP3」を X にシェアできる。投稿に手のサイズは入らない。

## 3. 画面と流れ(設計 1/4)

### 3.1 ページ `/mouse`(新規・ログイン不要・PC とスマホの両方)

1. **手の情報がそろっていないとき**
   - マイ設定に「手の長さ・手の幅・持ち方」のどれかが足りなければ、ページの上で入力してもらう。入力はマイ設定に保存する。
   - 「手の測り方」を図で案内する(長さ=手首のしわから中指の先まで、幅=親指を除いた4本の付け根の幅)。図は SVG で自作し、外部の画像は使わない。
   - 持ち方(かぶせ・つかみ・つまみ)は、それぞれ簡単な図と一言の説明から選ぶ。
2. **結果**(そろっていれば、開いた時点で出す)
   - 上に「あなたの目安」を出す。例:「かぶせ持ち・手の長さ 18.5cm → 長さ 114〜122mm・幅 53〜59mm くらいのマウス」。
   - その下に、合う順のマウス一覧(最初は上位 10 件、「もっと見る」で全部)。
     - カードの中身:メーカー・製品名、長さ・幅・高さ・重さ・形(左右対称/右手用)・接続(有線/無線)、合う度(0〜100)、合う理由の一言。
     - ボタン:「公式ページ」「Amazon で探す」「楽天で探す」。成果報酬付きのときは「PR」を表示する(5.2)。
   - 絞り込み:重さ(〜55g/〜70g/それ以上)、形、接続。並び順は「合う順」のまま変えない。
3. **今のマウスとの比較**
   - マイ設定に登録したマウスがデータにある場合、カードごとに「今のマウスより長さ −4mm・重さ −12g」のように出す。
   - 登録したマウスが自由入力でデータにない場合は、比較を出さない。
4. **シェア**
   - 「私に合うマウス TOP3」を X に投稿できる。投稿文は製品名 3 つと `/mouse` の URL。手のサイズは入れない。
   - `/mouse` の X 用画像(opengraph-image)は固定の画像。人ごとの画像は作らない。

### 3.2 ほかの画面
- ヘッダーに「マウス探し」を足す(スマホでは折り返す)。
- マイ設定の「手と持ち方」の欄に「合うマウスを探す」へのリンクを足す。

## 4. 合う順の計算(設計 2/4)

`src/lib/mouse-fit.ts`(新規)。係数は1か所にまとめ、あとで調整できるようにする。

### 4.1 目安の大きさ
- マウスの長さの目安 = 手の長さ(mm)× 係数:かぶせ 0.64、つかみ 0.60、つまみ 0.56
- マウスの幅の目安 = 手の幅(mm)× 係数:かぶせ 0.62、つかみ 0.60、つまみ 0.56
- 目安の範囲:長さ ±4mm、幅 ±3mm
- 例:かぶせ持ち、手の長さ 18.5cm・幅 9cm → 長さ 約 118mm(114〜122)、幅 約 56mm(53〜59)
- 係数は、一般に使われている手のサイズ表の考え方を元にした**仮の値**。本人が手応えを確かめ、違えば直す。

### 4.2 並べ方
- ずれの距離 d = √( ((長さ − 長さの目安) ÷ 6)² + ((幅 − 幅の目安) ÷ 4)² )
- d が小さい順に並べる。同じなら軽いほうを上にし、それも同じなら id の順。
- 合う度 = round(100 × max(0, 1 − d ÷ 3))
- 手の幅が未入力のときは、長さの項だけで d を計算し、「幅も入れると精度が上がります」と案内する。
- 持ち方が未入力のときは結果を出さず、選んでもらう。

### 4.3 合う理由の一言(長さと幅それぞれ)
- 範囲内:「長さが目安どおり」
- 範囲より小さい:「長さがやや短め(細かい操作向き)」
- 範囲より大きい:「長さがやや長め(安定しやすい)」
- 幅も同じ形(「幅が目安どおり」「幅がやや狭め」「幅がやや広め」)。

### 4.4 今のマウスとの比較
- 長さ・幅・高さ・重さの差を出す(例:「長さ −4mm・重さ −12g」)。
- 差の絶対値が 1 以下なら「ほぼ同じ」。

### 4.5 絞り込み
- 重さ・形・接続で絞れる。絞り込んでも並び順は変わらない。
- 0 件になったら「条件を減らしてください」と、絞り込みを外すボタンを出す。

## 5. データ(設計 3/4)

### 5.1 マウスの表 `src/data/mice.ts`(新規)

```ts
type MouseSpec = {
  id: string;            // src/data/devices.ts の id と同じ(マイ設定の「今のマウス」とつなぐ)
  lengthMm: number;
  widthMm: number;       // いちばん広いところ
  heightMm: number;
  weightG: number;       // 標準の構成(公式の表記どおり)
  shape: "symmetric" | "right";
  connection: "wired" | "wireless";
  officialUrl: string;   // 数字の出典(メーカー公式の製品ページ)
  checkedAt: string;     // 確認した日(YYYY-MM-DD)
};
```

- 対象:今の候補(`devices.ts`)にあるマウス 30 本。メーカー名と製品名は `devices.ts` を使う。
- 調べ方:実装のとき、メーカー公式の製品ページを1本ずつ開いて数字を写す。
  - 公式に数字がない項目は推測で埋めない。そのマウスは表から外し、「外したもの」として報告する。
  - 色違い・重さ違いがあるものは、いちばん標準の型にする。
- 増やすとき:`devices.ts` と `mice.ts` の両方に足す。
- 本人が一覧(製品名・数字・出典)を目で確かめる。マイ設定で未確認だった製品名(CORSAIR M75 WIRELESS など)も、ここで一緒に確かめる。

### 5.2 リンク `src/lib/shop-links.ts`(新規)
- 公式ページ:`officialUrl`。
- Amazon・楽天:メーカー名+製品名の検索ページへのリンク。
- 環境変数 `NEXT_PUBLIC_AMAZON_ASSOCIATE_TAG`・`NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID` が設定されていれば、成果報酬付きのリンクにする。設定は、審査が通ってから本人が Vercel で入れる。
- 成果報酬付きのときだけ、ボタンの横に「PR」と出し、ページ下に広告表記(`/disclosure`)へのリンクを置く。
- 外部リンクには `rel="sponsored noopener noreferrer"`(公式ページは `noopener noreferrer`)と `target="_blank"` を付ける。

### 5.3 DB・サーバー
- 使わない。データは JS に同梱し、計算はブラウザだけで行う。
- 手の大きさはマイ設定に入るだけで、新しい個人の情報は集めない。

## 6. エラーのとき・テスト(設計 4/4)

### 6.1 エラーのとき

| 状況 | 動き |
|---|---|
| 手の長さ・幅が範囲外(マイ設定と同じ:長さ 10〜25cm、幅 5〜15cm) | その場で注意を出し、保存しない |
| 持ち方が未選択 | 結果の代わりに持ち方の選択を出す |
| 絞り込みで 0 件 | 「条件を減らしてください」と、絞り込みを外すボタン |
| 今のマウスがデータにない | 比較だけ出さない |
| localStorage が使えない | その場の入力だけで結果を出し、「保存できませんでした」と小さく出す |

### 6.2 テスト
- **単体(Vitest)**
  - 係数どおりの目安、並び順(距離 → 重さ → id)、合う度の端(d=0 → 100、d≥3 → 0)
  - 幅が未入力のときの並べ方
  - 今のマウスとの差と「ほぼ同じ」
  - 理由の一言の境目
  - データの整合(id が `devices.ts` にある、数字の範囲:長さ 90〜140mm・幅 50〜80mm・高さ 20〜50mm・重さ 30〜150g、`officialUrl` が https)
  - リンク(検索語のエンコード、タグの有無で URL と PR 表記が切り替わる)
  - シェア文に手のサイズが入らない
- **ブラウザ(本番ビルドで確かめる)**:マイ設定が空 → 入力 → 結果 → 再読み込みで残る/絞り込み/もっと見る/スマホ幅/X 用画像が 200
- **公開前**:差分のセキュリティ監査(quick)。外部リンクの rel、シェア URL の作り方、環境変数の扱いを見る。
- **本人の確認**:マウスの一覧の数字と出典、係数の手応え。
