## 1. 目的と成功の基準

**目的**
- 毎日1文字の漢字を、FPS と同じ視点操作でなぞるエイム練習を作る。
- 「毎日来る理由」と「X でシェアされる看板」にする。
- 感度はマイ設定の値を使い、ゲームでの練習になるようにする(振り向き何 cm を再現する)。

**成功の基準**
- マイ設定の感度・DPI で、振り向き何 cm が感度計算ツールと一致する。
- だれでも何回でも練習でき、ログインした人は自己ベストがその日のランキングに載る。
- 結果を X にシェアでき、`/aim` の X 用画像がその日の文字になる。
- ランキングに Discord の名前・ID が出ない。利用停止・BAN の人も出ない。

## 3. 画面と流れ(設計 1/4)

### 3.1 「今日の文字」ページ `/aim`(新規)
- 今日の文字(大きく)、日付、「練習する」ボタン、自分の今日のベスト、今日のランキング上位10人と自分の順位。
- ログインしていない人には「ログインするとランキングに載ります」と案内する。
- タッチ操作だけの端末(`(pointer: fine)` に当てはまらない端末)では「PC(マウス)で遊べます」と表示する。今日の文字とランキングは見られる。

### 3.2 プレイの流れ(同じページ内、画面いっぱい)
1. マイ設定にメインゲーム・その感度・DPI がそろっていなければ、ゲーム・感度・DPI を聞く(マイ設定にも保存)。
2. 画面をクリックすると、ポインターロックで視点操作になる(カーソルが消え、クロスヘアが中央に出る)。3・2・1 で開始する。
3. 各画の始点に丸を出す。クロスヘアが丸に入ると、その画のなぞりが始まる。終点まで線に沿って動かす。これを最後の画まで繰り返す。
4. Esc などでポインターロックが外れたら中断する。その回は記録しない。

### 3.3 結果の画面
- 点数、正確さ(%)、時間、画ごとの正確さ、今日の自己ベスト。
- 「もう一度」と「X でシェア」のボタンを置く。
- ログインしていれば、自己ベストをランキングに送る。

### 3.4 そのほか
- マイ設定に「クロスヘア」の欄を足す(プレビュー付き)。`/aim` からも開ける。
- ヘッダーに「今日の文字」を足す(スマホでは折り返す)。

## 4. 視点の操作と採点(設計 2/4)

### 4.1 感度の再現
- 1カウントあたりの回転角(度)= 感度 × そのゲームの yaw(`src/data/sensitivity.ts` の `SENS_GAMES`。感度計算ツールと同じ係数)。
- マウスの移動量には、ポインターロックの `movementX` / `movementY` を使う。
  - 使えるブラウザでは `requestPointerLock({ unadjustedMovement: true })` を使い、OS の加速を切った生の値を使う。
  - 使えないブラウザでは通常の値を使う。
  - どちらの場合も、「OS のポインター速度やマウスの加速によっては少しずれます」と小さく注記する。
- 縦の回転も同じ係数を使う(縦横の感度倍率は1)。上下は ±89° で止める。

### 4.2 見え方
- 文字の板は、正面の距離 1 の平面に置く。横の視野角は 103° に固定する。
- 文字は横におよそ 40° の幅で置く。KanjiVG の座標(109×109)を角度に対応させる。
- 画面への投影は、視線と板の点の角度の差を `tan` で変換する(遠近あり)。
- 色(役割に合わせる):
  - 背景:`--rl-bg`
  - まだなぞっていない線:`--rl-secondary`(パープル)
  - 今なぞる画と始点の丸:`--rl-accent`(シアン)
  - なぞった軌跡:`--rl-tertiary`(ライム)
  - 外れているとき:`--rl-danger`

### 4.3 採点
- 各画の線(KanjiVG の path)を折れ線(細かく刻んだ点の列)にし、毎フレーム、クロスヘアが指す板上の点との距離を測る。
- 許容範囲:板の座標で 6(109×109 の中で)。
- **正確さ**:その画をなぞっている間のフレームのうち、線に沿って前に進んだフレーム ÷(前に進んだフレーム + 許容範囲の外だったフレーム)。許容範囲内でも前に進んでいないフレーム(始点の丸で止まっているなど)は数えない(2026-09-29 の実装時の判断。線の上で止まって正確さを稼ぐのを防ぐ)。全画の平均を 0〜100% とする。
- **進み具合**:クロスヘアの位置を線に投影し、線の上をどこまで進んだかを記録する。許容範囲内で前に進んだときだけ更新し、逆走や近道では増えない。95% に達したら、その画は完了とする。
- **点数** = `round(正確さ(0〜1) × 10000 × min(1, 目安時間 ÷ かかった時間))`
  - 目安時間 = 画数 × 1.5 秒
  - 最大 10,000 点

### 4.4 不正への備え(完全には防げない)
- 点数はサーバーで、正確さと時間から計算し直す。画面の点数は使わない。
- 次のものは受け付けない。
  - 日付(日本時間)が今日でない
  - 文字の id が今日のお題でない
  - 時間が「画数 × 300ms」未満
  - 正確さが 0〜100 の外
  - 同じ人の前回の送信から 10 秒以内
- 1人1日1行。自己ベスト(点数が高いとき)だけ上書きする。

## 5. お題・クロスヘア・データ(設計 3/4)

### 5.1 お題の文字
- KanjiVG のうち使う文字だけを、事前にスクリプトで JSON(画ごとの path)に変換し、`src/data/aim-chars.json` として同梱する。実行中に外部からは取らない。
  - 変換スクリプトは `scripts/kanjivg-to-json.mjs`。KanjiVG の SVG(使う文字の分だけ)を読んで JSON にする。取得元とバージョンを記録する。
  - KanjiVG のファイルの取得(ダウンロード)は、実装のときに本人の許可をもらってから行う。取得した SVG はリポジトリに入れない。変換後の JSON だけを入れる。
- 最初の一覧は約60字。画数の少ない字から順に並べる。Claude が選び、本人が確認する。
- その日の文字の決め方:`index = (日本時間の今日 − 開始日 2026-11-01 の日数) mod 字数`。開始日より前は index 0。
- 出典:
  - `/aim` と規約(クレジット欄)に「文字データ:KanjiVG(CC BY-SA 3.0)© Ulrich Apel」とリンクを表記する。
  - `aim-chars.json` の横に、同じ条件である旨の LICENSE ファイルを置く。

### 5.2 クロスヘア(マイ設定の版 2)
```ts
type Crosshair = {
  shape: "cross" | "dot" | "circle" | "cross-dot";
  color: string; // #RRGGBB
  length: number; // 1〜20(px)
  thickness: number; // 1〜6
  gap: number; // 0〜10
  outline: boolean;
};
```
- 色の候補(8色):
  - ブランドの4色:シアン・マゼンタ・パープル・ライム
  - 白・黄 #ffe14d・赤 #ff6b6b・緑 #4dff88
  - 自分で指定もできる。
- `MySettings` を版 2 にして、`crosshair` を足す。
  - 初期値:十字、シアン、長さ 6、太さ 2、隙間 3、縁取りあり
  - 版 1 のデータは読み込み時に初期値を足して版 2 に変換する。
- `save_my_settings` を版 2 に対応させる(版 1 も受け付けて、サーバー側で変換して保存する)。上限値の一致テストを足す。
- 公開カードの項目は変えない(クロスヘアは名刺画像に載せない。載せるかは後で決める)。

### 5.3 ランキングのデータ
表 `aim_scores`:

| 列 | 型 | 内容 |
|---|---|---|
| play_date | date | 日本時間の日付 |
| user_id | uuid | auth.users(id) を参照。削除で CASCADE |
| char_id | text | お題の文字の id |
| accuracy | numeric(5,2) | 0〜100 |
| time_ms | int | かかった時間 |
| score | int | サーバーで計算した点数 |
| submitted_at | timestamptz | 最後に送信した時刻(連続送信の判定に使う) |
| PK | (play_date, user_id) | |

- RLS は有効にし、ポリシーは作らない(関数経由だけ)。
- `submit_aim_score(p_date, p_char_id, p_accuracy, p_time_ms, p_strokes)`(authenticated):
  - 4.4 のチェックを行い、点数を計算し、自己ベストのときだけ更新する。
  - 今日の文字は、DB 側にも文字の一覧(`aim_chars`:順番 idx・文字 id・画数)を持ち、5.1 と同じ式で日付から idx を計算して決める。画面側の一覧(`aim-chars.json`)と一致することをテストで確かめる。一覧を増やすときは、JSON と migration を両方足す。
- `get_aim_ranking(p_date)`(anon・authenticated):
  - 上位10件を返す。項目は順位、表示名、点数、正確さ、時間。
  - 表示名はマイ設定の `cardName`。名刺を公開していない・未設定・公開禁止なら「名無しのゲーマー」(2026-09-29 の実装時の判断を、2026-09-30 に本人が承認。公開していない名前を誰でも見られる形で出さないため)。
  - 利用停止・BAN の人は除く(`_my_settings_block_reason` を使う)。
  - Discord の名前・ID は返さない。
- `my_aim_rank(p_date)`(authenticated):自分の順位と自己ベストを返す。

## 6. シェア・エラー時・テスト(設計 4/4)

### 6.1 シェア
- 投稿文の例:「今日の文字【炎】 8,420 点(正確さ 91%・12.3 秒) #ロビラボ #今日の文字」と `/aim` の URL。
- `/aim` の opengraph-image は、その日の文字(大)と日付で描く。1日ごとに変わるので、キャッシュは日付単位にする。
- 自分の点数入りの画像は今回は作らない。

### 6.2 エラーのとき
| 状況 | 動き |
|---|---|
| ポインターロックが使えない・拒否された | 「このブラウザでは遊べません」と表示し、Chrome / Edge / Firefox を案内 |
| 感度が未設定 | プレイ前に入力を聞く(3.2) |
| ランキングに送れない | 結果は表示したまま、「送れませんでした」ともう一度送るボタン |
| 日付をまたいだ | 始めた時点のお題で採点し、送信時に日付が変わっていれば送らず、その旨を表示 |
| 中断(ポインターロックが外れた) | その回は破棄し、「もう一度」を出す |

### 6.3 テスト
- **単体(Vitest)**
  - 感度から角度への変換(振り向き何 cm が `cm360` と一致)
  - 投影(角度 ↔ 画面座標)
  - 線との距離と進み具合(逆走・近道で進まない)
  - 点数の計算
  - その日の文字の決め方(日本時間の境目)
  - クロスヘアの入力チェック
  - マイ設定の版 1 → 2 の変換
  - 画面側と DB 側のお題一覧・上限の一致
- **RLS(dev)**
  - 送信のチェック(日付違い・文字違い・速すぎ・範囲外・10秒以内の連続送信を弾く)
  - 自己ベストだけが残る
  - ランキングに利用停止・BAN の人が出ない
  - 表示名が cardName か「名無しのゲーマー」で、Discord 情報を返さない
  - anon でもランキングは読める
- **手での確認(本人)**:PC で実際に遊び、ゲームと同じ感度の手応えか確かめる。
- **公開前**:差分のセキュリティ監査(quick)。
