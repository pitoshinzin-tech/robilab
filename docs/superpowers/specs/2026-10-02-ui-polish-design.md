# ロビラボ UI 磨き込み 設計書(デザインシステムと画面ごとの設計)

- 日付:2026-10-02
- ブランチ:`feat/ui-polish`
- もと:`docs/design/ui-audit-2026-10-02.md`(監査)、plan.md D29(ネオンのトーン)・D30・D33・D37〜D39、2026-10-02 の進捗(CEO が仮に決めた 5 つの方針)
- 前提(決定済み・この設計書では変えない)
  1. シアン(`--rl-accent`)は押せるものだけ。強調の数字はマゼンタ。選んだ状態はパープルの枠。ふつうの枠は白の半透明。
  2. 部品は入っている shadcn/ui(base-ui)の `src/components/ui/*` を土台に、`--rl-*` に合わせて作り直す。
  3. スマホは下のタブバー(今日の文字・診断・マウス・仲間・マイ設定)。押せる所は 44px 以上。今いる場所の印。PC は上のヘッダー。
  4. トップの主役は今日の文字。その下に「自分を知る(診断)」「感度・マウス」「仲間を探す」。
  5. 16 タイプは 4 軸から形と色を決める仮のドット絵(社長の絵ができたら差し替え)。
  6. アイコンは lucide-react の SVG。絵文字はアイコンに使わない。
  - 新しいライブラリは足さない(package.json にあるものだけ)。

---

## 1. 分析サマリー

- 業種:ゲーマー向けのハブ(診断・道具・仲間探し)。相手は日本の 10 代後半〜20 代の FPS 好き。スマホで来て PC で遊ぶ。
- 強み:色の役割の考え方と、文言の丁寧さ、`/aim` の状態の作り込み。
- 弱み:共通部品が使われておらず、ボタン・カード・入力欄の見た目が 6〜8 通りに割れている。フォーカス・ホバー・押した状態・44px がない。
- ブランドの「らしさ」が文字の色ズレ 3 か所だけ。16 タイプの絵が全部同じで、一覧の楽しさが出ない。
- 方針:ネオンは「押せるシアン」と「数字のマゼンタ」に絞り、目立たせる所は 1 か所(今日の文字の大きな漢字)。ほかは静かに整える。

## 2. デザインシステム

### 2-1. 色の役割のトークン

面は**不透明**にする(今の `--rl-surface` は白 5% の透明で、背景のグラデの上でコントラストが変わるため)。グラデは `body` の背景だけに残す。

- フォーカスの線を押せる色と同じにする理由:フォーカスが付くのは押せるものだけなので、「シアン = 押せる」の意味がむしろ強まる。主ボタン(シアンの塗り)の上でも、2px 離すので背景の色の隙間ができて見える。
- 今の `--rl-border`(シアン 35%)はやめて `--rl-line` / `--rl-line-strong` に置き換える。`--rl-cyan` などの色の名前を画面で直接使うのはやめ、役割の名前だけを使う(色の名前のトークンは `:root` の中の定義だけに残す)。
- shadcn の変数は `--rl-*` に向ける(白いテーマと `.dark` は消す):`--background → --rl-bg`、`--foreground → --rl-text`、`--card / --popover → --rl-surface`、`--primary → --rl-accent`、`--primary-foreground → --rl-on-accent`、`--secondary / --muted / --accent(shadcn の「ホバーの面」の意味)→ --rl-surface-2`、`--muted-foreground → --rl-muted`、`--destructive → --rl-danger`、`--border → --rl-line`、`--input → --rl-line-strong`、`--ring → --rl-focus`。`@layer base` の `body { bg-background text-foreground }` は、向け先を変えたあとなら残してよい(白くならない)。
- `:root { color-scheme: dark; }` と、`<meta name="theme-color" content="#0A0C16">`(`viewport` の書き出し)を入れる。フォームの部品やスクロールバーも暗くなる。

### 2-2. 文字

**書体の役割**(`layout.tsx` で確認:Zen Kaku Gothic New 500/700、Orbitron 700/900)

| 書体 | 役割 | ルール |
|---|---|---|
| Zen Kaku Gothic New | 日本語の本文・見出し・ボタン・ロゴ(カタカナ) | 本文 500、見出し・ボタン 700。ロゴと今日の漢字の横の大見出しだけ 900 を足す(同じフォントの太さを足すだけで、新しいライブラリではない) |
| Orbitron | タイプのコード(ARCH)、大きな数字(点数・cm・%・順位・進捗 3/12)、英字のサブロゴ ROBILAB | 日本語には使わない。14px 未満では使わない。数字は `tabular-nums`。英字のラベルを全部大文字で字間を広げて見出しの上に置く使い方はしない(今のトップのタグラインはやめる) |

- Zen Kaku の `subsets` と日本語の表示の速さは、本番のビルドで確かめる(監査 26)。

### 2-4. 動き

| 種類 | 時間 | easing | 使う所 |
|---|---|---|---|
| すぐ(押した手応え) | 120ms | `cubic-bezier(0.2, 0, 0, 1)` | ホバー・押した状態・チップの選択 |
| ふつう(開く・閉じる) | 200ms | 入る `cubic-bezier(0.2, 0, 0, 1)` / 出る `cubic-bezier(0.4, 0, 1, 1)` | 折りたたみ・メニュー・トースト |
| 見せ場(1 か所だけ) | 480ms | `steps(8)` | 診断の結果でタイプのアイコンがドットから組み上がる |

- トークン:`--rl-dur-fast: 120ms; --rl-dur-base: 200ms; --rl-ease-out: cubic-bezier(0.2,0,0,1); --rl-ease-in: cubic-bezier(0.4,0,1,1);`
- 自動で動くものは見せ場の 1 か所だけ。セクションが下からふわっと出る動き・カード全部のホバーの拡大はしない。
- 色ズレ(`rl-glitch`)は止まったまま。点滅させない(光の点滅は WCAG 2.3.1 の危険)。
- `prefers-reduced-motion: reduce` のとき:`globals.css` で `*, ::before, ::after { animation-duration: .01ms; animation-iteration-count: 1; transition-duration: .01ms; scroll-behavior: auto; }`。スケルトンの点滅は止めて、色だけの面にする。見せ場はアイコンをそのまま出す。`/aim` の視点の動きは本人の操作なので止めない。

### 2-5. 部品の一覧と仕様

すべて `src/components/ui/*`(base-ui)を作り直すか、そこに足す。画面では直書きのクラスをやめ、部品を使う。

**共通の状態のルール**(全部の押せる部品)
- `cursor-pointer`。無効のときは `cursor-not-allowed`。
- `focus-visible:outline-2 outline-offset-2 outline-[var(--rl-focus)]`(`ring` ではなく `outline` にして角丸に沿わせる)。マウスで押したときは出さない。
- 押した状態:`active:translate-y-px` と明るさ 95%。
- 無効:不透明度 45%、`aria-disabled`。押しても何も起きない見た目にする(監査:`disabled` の見た目がない 4 か所)。
- 押せる大きさは 44×44px 以上。見た目が小さい部品は、見えない広がり(`before:` の疑似要素 `-inset-2`)で 44px にする。

**Button**(`ui/button.tsx` を作り直す)

| variant | 見た目 | 使う所 |
|---|---|---|
| `primary` | `--rl-accent` の塗り、`--rl-on-accent` の文字。ホバーで `--rl-accent-hover` + `--rl-glow-1` | 画面(スクロールしないで見える範囲)で一番やってほしいこと。**1 画面に 1 つ** |
| `secondary` | `--rl-surface-2` の塗り、`--rl-line-strong` の枠、`--rl-text` の文字。ホバーで枠が `--rl-text` 60% | 二番目の行動(シェア・保存・コピー) |
| `ghost` | 塗りなし、`--rl-muted` の文字。ホバーで `--rl-text` と下線 | 戻る・もう一度診断する・ブロック・通報 |
| `danger` | 塗りなし、`--rl-danger` の枠と文字。確かめるダイアログの中の最後のボタンだけ `--rl-danger` の塗り + `--rl-bg` の文字 | 退会・設定を消す・記録を消す |
| `discord` | `--rl-discord` の塗り、白の文字、Discord のロゴ(SVG) | Discord ログインだけ |

| size | 高さ | 横の余白 | 文字 |
|---|---|---|---|
| `sm` | 44px(`h-11`) | 16 | 14px 太字 |
| `md`(標準) | 48px(`h-12`) | 24 | 16px 太字 |
| `lg` | 56px(`h-14`) | 32 | 16px 太字 |
| `icon` | 44×44 | — | アイコン 20px。`aria-label` 必須 |

- 角丸は `--rl-radius-pill`。アイコンは左(進む意味のときだけ右)、20px、文字との間 8px。文字の後ろに「→」を書かない。
- `loading`:左に `Loader2`(回転、reduced-motion のときは回さない)、文字を「〜中…」に変える(例:「保存中…」)、`aria-busy="true"`、押せなくする。幅が変わらないよう `min-w` を保つ。連打で 2 回動かない(監査:`LoginButton`)。
- `Link` に使うときは base-ui の `render` で `<Link>` を描く(見た目だけボタンの `<a>`)。

**Card**(`ui/card.tsx` を作り直す)

| variant | 見た目 |
|---|---|
| `default` | `--rl-surface`、`--rl-line` の枠、`--rl-radius-md`、`p-4 md:p-6` |
| `interactive` | カード全体がリンク。ホバーで地が `--rl-surface-2`、枠が `--rl-line-strong`。右に `ChevronRight`(押せると分かる印)。`cursor-pointer`、フォーカスの線 |
| `selected` | `--rl-selected` の 2px の枠 + `--rl-selected-bg` |
| `feature` | トップの今日の文字だけ。枠は `--rl-line-strong`、中の漢字に `--rl-glow-2` |

- 中の見出しは 20px、補足は 14px。カードの中にカードを入れない(区切りは `--rl-line` の線)。
- 同じ形のカードを並べるのは「同じ種類のものの一覧」のときだけ(マウス・候補・タイプ)。説明の文章をカードで細切れにしない。

**Input / Select / Label**

## 4. アンチパターン(やってはいけないこと)

1. シアンを飾り・数字・見出し・枠に使う。押せる色の意味が消える。
2. 1 画面に主ボタンを 2 つ以上置く。ナビやチップをシアンにする。
3. 絵文字をアイコンに使う。文言の後ろに「→」を付ける。
4. 文字を光らせる(グローを本文や小さい文字に付ける)。にじんで読めない。光は今日の漢字と主ボタンのホバーとタイプの絵だけ。
5. 色ズレや画面のノイズを点滅・ちらつかせる(光の点滅は発作の危険。WCAG 2.3.1)。
6. 「ゲーマーっぽさ」の決まり文句:血の赤、カーボン柄、斜めの六角形の HUD をどこにでも、虹色に流れる RGB、とがった英字の書体を日本語に使う。D29 は「今どき + 懐かしいドット絵」で、戦場の雰囲気ではない。
7. アフィリエイトの暗いやり方:PR を隠す・小さくする、「残りわずか」「今だけ」の急かし、値段や効果の決めつけ、ボタンの文言で店へ行くと分からない書き方(「詳しく」だけ)。店へ行くボタンは「Amazon で見る」と行き先を書く。
8. ガチャ・くじ・課金の見た目(光る宝箱、レア度の色)。10 代も見るサイトで、お金を使わせる見た目はしない。
9. 仲間探しを出会い系に見せる:顔写真の大写し、ハート、「マッチ」の演出、年齢や性別を前に出す。法律の心配(plan.md)があり、ゲームの話に絞る。
10. Discord 名を相互 OK の前に見せる、見せそうな見た目(ぼかしで透けるなど)。
11. ランキングでさらし者にする(最下位の表示、名前の横に「下手」など)。上位と自分の位置だけ。
12. 12px 未満の文字。12px にエラー・注意・説明を入れる。
13. 純粋な黒 `#000` の地と純粋な白 `#FFF` の文字(目が疲れ、ネオンが浮く)。
14. ライトテーマの切り替えを作る(2-1 の理由)。
15. 見出しの上に英字の大文字ラベルを毎回付ける、意味のない番号(01 / 02 / 03)。番号は本当に順番があるとき(診断の進み、ロビーの流れ、登録の段)だけ。
16. セクションごとのふわっと出る動き、カード全部のホバーの拡大。
17. 新しいライブラリ(アニメーション・アイコン・UI キット)を足す。

   - A(おすすめ):スマホでも今日の文字を一番上に出す。ボタンは「ランキングを見る」と「PC で遊ぶリンクをコピー」。すぐ下の診断の入口に主ボタンを置く。毎日来る理由を全員に見せられる。
   - B:スマホだけ診断を一番上にし、今日の文字はその下。
   - C:スマホも PC も同じ(遊べないことは押してから知らせる)。
2. **冷静(Z)タイプの絵の色**
   - A(おすすめ):淡いパープル #A99BFF にする(シアンを押せる色に残すため)。熱血(H)はマゼンタ。
   - B:今のシアンのまま(絵だけは例外にする)。
   - C:ライムにする(明るく元気な見た目になる)。
3. **ネオンの光(グロー)の強さ**
   - A(おすすめ):控えめ。光るのは今日の漢字・結果のタイプの絵・主ボタンのホバーだけ。
   - B:強め。カードの枠もいつもうっすら光る(にぎやかだが、押せる所が分かりにくくなる)。
   - C:光なし。色ズレだけ。
