# タイプコードの文字(叩き台 v0.1)

> 状態:【仮】本人の確認待ち(plan.md「未決定の論点:タイプコードの文字とタイプ名」)

## 決めごと

- 並び順は **軸1(攻め/守り)→ 軸2(直感/戦略)→ 軸3(チーム/ソロ)→ 軸4(熱血/冷静)** で固定。
- 8文字すべて別の文字にする(同じ文字が2つの軸に出ない)。
- MBTI と混同されないよう、MBTI の文字 **E・I・S・N・T・F・J・P は使わない**。
  → 使える文字:A B C D G H K L M O Q R U V W X Y Z

---

## 案①(おすすめ):A G / R B / C L / H Z

| 軸 | 左 | 右 |
|---|---|---|
| 攻め / 守り | **A**(Attack) | **G**(Guard) |
| 直感 / 戦略 | **R**(Reflex:反射) | **B**(Brain:頭脳) |
| チーム / ソロ | **C**(Crew:仲間) | **L**(Lone:一匹狼) |
| 熱血 / 冷静 | **H**(Hot) | **Z**(Zone/Zen:ゾーン・無心) |

16通り:ARCH / ARCZ / ARLH / ARLZ / ABCH / ABCZ / ABLH / ABLZ / GRCH / GRCZ / GRLH / GRLZ / GBCH / GBCZ / GBLH / GBLZ

- 変な単語・悪い意味になるものは見当たらない。
- **ARCH(アーチ)** だけ英単語になるが、意味は「弓形」「大〜(archenemy など)」で、むしろ主人公っぽい。
- ABC で始まる ABCH / ABCZ は少し目立つが、悪い意味はない。

## 案②:A D / V L / U O / H C

| 軸 | 左 | 右 |
|---|---|---|
| 攻め / 守り | **A**(Attack) | **D**(Defense) |
| 直感 / 戦略 | **V**(Vibe:ノリ) | **L**(Logic) |
| チーム / ソロ | **U**(Unit) | **O**(One) |
| 熱血 / 冷静 | **H**(Hot) | **C**(Cool) |

例:AVUH / DLOC / ALOH / DVUC

- Hot / Cool がいちばん直感的に伝わる。
- ただし U・O が母音なので「ALOH(アロハ?)」「DLOC」など読み方に迷うものが出る。
- A と D は、社内で呼んでいる「軸A〜D」と文字がかぶってまぎらわしい。

## 案③:R K / V M / W O / B C

| 軸 | 左 | 右 |
|---|---|---|
| 攻め / 守り | **R**(Rush) | **K**(Keep) |
| 直感 / 戦略 | **V**(Vibe) | **M**(Mind) |
| チーム / ソロ | **W**(We) | **O**(One) |
| 熱血 / 冷静 | **B**(Blaze:炎) | **C**(Cool) |

例:RVWB / KMOC / RMOB / KVWC

- 「Rush / Blaze」はゲームっぽくてかっこいい。
- 子音が続くので声に出しにくい(RVWB など)。X で「私 RVWB だった」と言いにくい。

---

## おすすめ:案①(A G / R B / C L / H Z)

理由:
1. **ゲーマーにすぐ伝わる言葉**:Attack / Guard は格ゲーのガード、Reflex / Brain は反射神経と頭脳、Crew / Lone は野良と一匹狼。説明なしでもなんとなく意味がわかる。
2. **Z(ゾーン)がゲーマー向き**:冷静=「ゾーンに入っている状態」と言い換えられて、クールさがポジティブに見える。ドット絵で「Z」のアイコンも作りやすい。
3. **声に出して読める**:ARCH(アーチ)、GBLZ(ジービーエルゼット)など、アルファベット読みでも詰まらない。変な単語にならない。
4. **軸の名前とかぶらない**:A 以外に「軸A〜D」と同じ文字がない。社内では軸を「軸1〜4」と呼ぶことにすれば完全に分けられる。

気になる点:H(Hot)と Z(Zone)の組み合わせは直感的ではない(Hot の反対は Cool のほうが自然)。C をチームに使っているため Cool が使えない。気になる場合は、チームを **U(Unit)**、冷静を **C(Cool)** にする「案①改:A G / R B / U L / H C」も可能(例:ARUH / GBLC)。
