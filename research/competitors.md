# 競合調査レポート:日本のゲーマー向け「16タイプ診断」サービス

調査日:2026-09-26(WebSearch / WebFetch による公開情報の調査。数値は出典の記載どおり。確認できなかった項目は「未確認」と書いています)

## 0. 先に結論(いちばん重要な発見)

- **「ゲーマー × MBTI風16タイプ × FPSのキャラ推薦」は、もう他のサービスがやっています。**
  - **FPS TYPE(fpstype.com)**:VALORANT と Apex 向け。16問の「MBTI風プレイスタイル診断」、おすすめエージェント、Riot ID 連携、5人の「チーム相性チェッカー」(2026年6月に追加)、デバイス紹介(Amazon アソシエイト)、AdSense。企画中サービスとの重なりが**最も大きい**競合です。
  - **FPS JAPAN の VALORANT エージェント適正診断**:10問・約1分。「MBTI風16タイプ対応」で、エイム傾向も質問に含まれます。
  - **Gamee のゲーマータイプ性格診断**:20問。国内最大級のゲーム友達募集アプリが**自社で診断を持っています**。2027年に予定している「相性マッチング」の領域を、すでに押さえている会社が診断もやっている、ということです。
- **ゲーム会社の公式診断もあります**:ストリートファイター6(カプコン)の「おすすめファイター&操作タイプ診断」、OW2(Activision Blizzard Japan、2023年のキャンペーン)の「ヒーロー診断」。
- よって、「診断がある」ことは差別化になりません。勝ち筋は **「5タイトルを横断した1つのタイプ」「意外と合わないキャラ」「エイム実測との組み合わせ」「グラフィックデザイナーが作る見た目(シェア画像)」** のような、組み合わせの部分にあります。

## 2. 企画中サービスの強み

1. **5タイトルを横断する「1つのタイプ」**:競合の診断は1タイトルだけ(FPS TYPE は2タイトル)。OW2・VALORANT・Apex・SF6・DbD をまとめて「あなたは〇〇型」と言える点は、確認した範囲では他にありません。
2. **「意外と合わないキャラ」**:確認した競合の中には、この結果を出すものは見つかりませんでした。意外性があるのでシェアや会話のネタになりやすく、16Personalities が流行った理由(会話のネタになる)と合っています。
3. **エイムの傾向+PCでの実測**:エイム練習ツールは単機能で、性格やキャラとはつながっていません。「性格の傾向」と「実測」を組み合わせたものは、確認した範囲では見当たりません。
4. **12問・約1分半・日本語だけ**:短さでは FPS JAPAN(10問・約1分)と同じくらいで、16Personalities(長め)より気軽です。
5. **グラフィックデザイナーが作る見た目**:診断サイトの多くは見た目が素っ気ないです。結果のシェア画像やタイプのキャラクター絵の出来が、そのままSNSで広がる力になります。
6. **デバイスのアフィリエイトとの相性**:「エイムの傾向 → おすすめのマウスや感度」という流れは、FPS TYPE もやっているように、自然な導線になります。

## 3. 企画中サービスの弱み・リスク(率直に)

1. **真似しやすく、すでに似たものがある**:FPS TYPE はコンセプトがほぼ同じで、しかも先にチーム相性まで作っています。診断のロジックは数日で真似できます。守れるものは「ブランド・キャラクター・データの量」しかありません。
2. **一度やったら終わりになりやすい**:診断は1回やれば目的を果たしてしまいます。ポケ徹のように「毎日開く理由」が今の企画にはありません。「長く愛される」という目標と、診断中心の作りは相性がよくありません。
3. **月25万円への道のりが遠い**:
   - 500円のレポートだけで達成しようとすると、決済手数料を引く前でも**月500件**売る必要があります。診断から有料への転換率がどのくらいかは**未確認**ですが、無料診断の結果にお金を払う人はごく一部なので、かなりの訪問数が必要です。
   - **X の収益化制度が変わりました**:従来の「クリエイター収益分配」は2026年8月7日で新規受付を停止し、9月7日で終了。新しい「Original Content Rewards」は「認証済みフォロワー500人以上+90日で50万ホームタイムライン表示以上」が条件で、オリジナルの投稿だけが対象です。**X の収益を事業の柱として見込むのは危険**です。
   - 広告やPV頼みは、GameWith のような大手でさえ市況の悪化で赤字になっています。
4. **ゲームタイトルの寿命と、運営方針の変化**:5タイトルの人気やキャラの追加・調整に合わせて、「合うキャラ」をずっと更新し続ける必要があります。1人で運営するには負担が大きいです。タイトルの人気が落ちると、そのまま集客も落ちます。
5. **2027年以降の機能は、法律・安全面のリスクが大きい**:
   - 相性マッチングや「今すぐ遊べる人」の掲示板は、Gamee(24時間監視、自動BAN、通報の仕組み)という強い相手がいる分野です。Gamee でさえ「通報によるBANが不公正」という不満が出ているように、**モデレーション(投稿やユーザーの管理)はとても大変**です。
   - 実際の使われ方が男女の出会いに寄ると、**出会い系サイト規制法**(公安委員会への届出、18歳未満でないことの確認など)に関わる可能性があります。「形の上では出会い目的ではない」サービスでも摘発例があるとされています。未成年が多いゲーマー層ではとくに注意が必要です。
   - 匿名の愚痴吐き場:「つながらないSNS ilka」「愚痴バブル」「ぐちったー」など、返信なしで共感だけのサービスはすでにあります。さらに、特定の個人(晒し)やプロ選手への誹謗中傷が投稿されたときの削除対応は、運営者に責任が生じます。
6. **「MBTI風」への批判**:MBTI の商標や、診断の科学的な根拠への批判は、東洋経済の記事などで話題になっています。「当たる」と言いすぎると炎上しかねません。「エンタメ」と明記したほうが安全です。
7. **日本語だけ**:国内の市場に限られます。Game8 が海外展開で伸びている(ログミー Finance の見出しより)のとは逆の方向です。ただ、1人運営の最初の段階なら妥当な判断です。

## 4. 差別化の提案(5つ)

1. **「意外と合わない」と「エイムの実測」を看板にする**
   競合にない2つを、結果画面とシェア画像のいちばん目立つところに置きます。例:「あなたは〇〇型。実はウィドウメイカーは合わない」「エイム実測:フリック型/トラッキング型」。「当たってる/当たってない」と言い合える形にして、会話のネタにします。

2. **診断を「毎日使う道具」に育てる(ポケ徹型)**
   エイム実測を**記録して、成長が見える**ようにします(週ごとの自己ベスト、タイプ別ランキング)。さらに「タイプ別・キャラの向き不向き」ページや「感度の換算ツール」など、ゲームのたびに開く理由を作ります。検索向けには「〇〇(キャラ名) 向いてる人」「〇〇 合わない」のようなページを、5タイトル×キャラの数だけ作れます。

3. **タイプのキャラクター化とデザインでブランドを作る**
   16タイプそれぞれにデザイナー自作の絵と二つ名を付けます(16Personalities のイラストと同じ役割)。これが真似されにくい部分になり、グッズ・スタンプ・壁紙など、500円レポート以外の収入源にもなります。

4. **「チーム・友達との相性」を先に、マッチングは後回しに**
   FPS TYPE のチーム相性チェッカーに対抗して、「友達とタイプを見せ合う」相性表示(URLを送るだけで、会員登録なし)を先に出します。見知らぬ人とのマッチングや掲示板は、法律とモデレーションのリスクが大きいので、**身内同士の相性 → Discord サーバー向けのBot(サーバー内だけのロール付与や相性表示)** の順に進め、公開のマッチングは最後にするのがよいです。

5. **収益源を分散させる(X の収益は「おまけ」扱い)**
   ① 500円レポートの中身を「診断結果+エイム実測データ+練習メニュー+デバイス提案」にして、実際に上達につながる価値を持たせる。② デバイスのアフィリエイトを、エイム傾向に合わせた提案にする。③ 実況者・配信者とのコラボ診断(「〇〇さんと同じタイプ」)で広める。X は集客の場所と割り切り、制度が変わっても困らない計画にします。
