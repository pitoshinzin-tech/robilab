# ゲーマー向け16タイプ診断サイト 収益見込みレポート

調査日: 2026-09-26 / 対象: 2026年12月末公開予定の個人開発サイト(日本語・12問・16タイプ、X シェア前提)
目標: **安定して月25万円**(本レポートでは「決済手数料などを差し引いた後の粗収益」で計算。サーバー代・税金は別)

> 表記ルール: 公式ページや複数の記事で確認できた数字は出典番号 [n] を付けています。確認できなかった数字は **未確認** または **推定** と書き、推定には根拠を添えています。

---

## 0. 結論(先に要点)

- 収益の柱は **(a) 500円レポート**。標準シナリオでは収益の約8割がここから出る。アフィリエイトと AdSense は1人あたりの単価が小さく、補助的な収益源にとどまる。
- 月25万円に必要な「診断の完了人数」は、**保守 約15万人/月、標準 約4.2万人/月、楽観 約1.3万人/月**。
- 標準シナリオで、公開12か月後の見込みは **月5万〜10万円前後**。月25万円を安定して得るのは、楽観シナリオ(高い購入率、継続的な拡散、マッチング課金の定着)がそろった場合に限られる。
- X の収益化は、2026年9月に新制度 **Original Content Rewards** へ移った。条件は「Premium 加入、認証済みフォロワー500人、過去90日で認証済みユーザーからの50万インプレッション」で、**対象はオリジナル投稿だけ**。ユーザーが自分の診断結果をシェアしても運営者には1円も入らない。お金になるのは運営者自身のアカウントのオリジナル投稿だけで、新制度の単価は未確認。
- 「安定」を重視するなら、マッチングは **月額制(年額プランも併設)** のほうが有利。ただし、マッチングには出会い系サイト規制法、電気通信事業法、未成年の利用という別の法的な論点がある。

## 2. 月25万円に必要な規模の逆算

### 2-1. 前提(1人が診断を完了するごとの期待収益 = RPD)

| 項目 | 保守 | 標準 | 楽観 | 根拠 |
|---|---|---|---|---|
| (a) レポートの購入率 | 0.3% | 1.0% | 2.5% | B2C フリーミアムの有料転換率は **1〜3%が標準、5%を超えれば優秀** [22][23]。今回はバズで来る「ついで」の訪問者が多く、1回きりの利用になるため、標準は下限寄りに置いた(**推定**) |
| (a) 1件あたり手取り | 482円 | 482円 | 482円 | 500円 × (1 − 3.6%) |
| (b) 結果画面からアフィリエイトリンクへのクリック率 | 3% | 6% | 10% | おすすめのゲーム・デバイス・ゲーマー飯・セルフケアの4枠を置く想定(**推定**。公開された統計なし) |
| (b) クリック後の購入率 | 2% | 4% | 6% | 物販アフィリエイトで一般に言われる1〜5%程度(**推定**) |
| (b) 1回の購入あたりの紹介料(ジャンル混合) | 120円 | 200円 | 300円 | デバイス: 8,000円 × 2% = 160円。エナドリ: 4,500円 × 8% = 360円。目薬: 1,000円 × 5% = 50円。同じカートの他の商品も対象(**推定**) |
| (d) 診断1回あたりのPV | 1.5 | 2.5 | 3.5 | トップと結果のページ、シェアから来た人の結果閲覧を含む。設問は1ページ内で切り替わる前提(**推定**) |
| (d) ページRPM | 100円 | 200円 | 350円 | 日本の平均は100〜400円 [20] |
| **RPD の合計** | **約1.67円** | **約5.80円** | **約15.08円** | (a) + (b) + (d) |
| (c) X 収益(運営者のアカウント、診断人数とは無関係) | 0円(条件未達)− Premium 980円 | 対象インプレッション月300万 → 約8,000円 − 980円 ≒ **7,000円** | 対象インプレッション月2,000万 → 約5万円 − 980円 ≒ **4.9万円** | **新制度の単価は未確認**。旧制度の単価(1万インプレッションあたり1〜5円 [17])を仮に使った。新制度で数えるのは Premium ユーザーの画面に表示された分だけなので、同じ表示回数でも数が少なく出る可能性がある(**推定**) |

### 2-2. 逆算の結果

**必要な診断完了人数 = (250,000円 − X の純収益) ÷ RPD**

| | 保守 | 標準 | 楽観 |
|---|---|---|---|
| **月あたりの診断完了人数** | **約15万人** | **約4.2万人** | **約1.3万人** |
| 1日あたり | 約5,000人 | 約1,400人 | 約440人 |
| レポートの購入件数/月 | 約450件 | 約420件 | 約330件 |
| (a) レポート | 約21.7万円 | 約20.2万円 | 約16.1万円 |
| (b) アフィリエイト | 約1.1万円(購入90件) | 約2.0万円(購入100件) | 約2.4万円(購入80件) |
| (d) AdSense | 約2.3万円(22.5万PV) | 約2.1万円(10.5万PV) | 約1.6万円(4.7万PV) |
| (c) X | −0.1万円 | 約0.7万円 | 約4.9万円 |
| **合計** | **約25万円** | **約25万円** | **約25万円** |

**読み取れること**
- どのシナリオでも、**レポートの購入が月330〜450件**必要になる。アフィリエイトと AdSense を合わせても、収益の1〜2割にとどまる。
- 「月4.2万人が毎月、新しく診断する」状態を維持するのが標準の条件になる。診断はふつう1人1回しか受けないので、**毎月4.2万人の新しいユーザーが必要**ということ(**推定**。リピートは少ない前提)。
- 仮に1人のシェアから平均0.3人が新しく診断するとしても、残りは自分の X での発信、新作ゲームに合わせた結果の更新、検索などから集め続ける必要がある(**推定**)。
- **上振れの手段**: ゲーミングPCの個別案件(約15万円 × 3.3%〜10% = 1件あたり約5,000〜15,000円)は、月10件で5〜15万円になる。単価の低い物販より効率が良い [13]。
- 経費(推定): サーバー代0〜3,000円、ドメイン約200円、バーチャルオフィス約660円〜、電話用SIM約1,000円、X Premium 980円で、**月3,000〜7,000円程度**。

## 3. 時期ごとの現実的な見込み

前提:
- 公開直後は Amazon が仮登録中(報酬は発生し、本審査に通れば支払われる)。AdSense は審査中または不合格の可能性があり、X の収益化は条件未達。
- バズで来た人は購入率が低い(**推定**)ため、公開月は楽観シナリオでも標準の RPD で計算した。

| 時期 | 保守 | 標準 | 楽観 | 主なリスク・マイルストーン |
|---|---|---|---|---|
| **2026年12月末〜2027年1月(公開直後)** | 2,000人 → **約3,000円** | 1.5万人 → **約8万円** | バズで8万人 → **約40万円(一時的)** | 最初の数日でシェアが広がるかどうか。Amazon の「180日以内に3件」は標準以上なら達成しやすい |
| **公開6か月後(2027年6月)** | 1,000人 → **約2,000円** | 8,000人 → **約5万円** | 2万人 → **約30万円 + X 約5万円 = 約35万円** | バズの反動で減少する時期。新作ゲームや季節のイベントに合わせて結果を更新し、流入を保てるか。X の条件達成は標準ではまだ難しい |
| **公開12か月後(2027年12月)** | 1,000人 → **約2,000円** | 1万人 → 約5.8万円 + X 約0.7万円 + マッチング月額60人(約2.9万円)→ **約9〜10万円** | 2.5万人 → 約37.7万円 + X 約4.9万円 + マッチング月額300人(約14.3万円)→ **約57万円** | マッチングの利用者が十分に集まるか(ユーザー数が少ないと成立しない) |

**所感**: 標準シナリオでは、**12か月後でも月25万円の半分以下(月5〜10万円)**が現実的な水準。個人開発の診断アプリで数百万円を稼いだ例もある [24]。ただし、それは多数の診断を量産し、アプリの動画広告で収益化した結果であり、1本の診断サイトとは条件が違う。

## 4. 買い切り(500円)と月額の比較(「安定収益」の観点)

| 観点 | 買い切り500円 | 月額(例: 500円/月) |
|---|---|---|
| 手取り | 約482円/件 | 約478円/月(Billing 手数料 0.7% を含む)[2] |
| マッチングだけで月25万円に必要な数 | **毎月 約520人の新規購入** | **有料会員 約523人を維持** |
| 維持に必要な毎月の新規獲得 | 520人(ずっと必要) | 月の解約率を8%(**推定**。B2C 少額サブスクで一般的な5〜10%の中間)とすると **約42人**。12か月で523人に届かせるには、毎月約80人の獲得が必要 |
| 収益の安定性 | 流入の量にそのまま連動し、ばらつきが大きい | 積み上げ型で安定しやすい。ただし立ち上がりは遅い |
| 向いている機能 | 1回で価値が完結するもの(詳細レポート、相性表) | 継続的な価値があるもの(マッチング、新しい相手の通知、優先表示) |
| 実装・法務の負担 | 軽い | 定期課金の表示義務が増える(2022年改正特商法の「最終確認画面」で、契約期間・自動更新・解約方法を表示する)[25]。解約の手段も必要 |
| 利用者の心理 | 500円なら気軽に買いやすい | 「解約が面倒」と思われやすい。未成年は家族のカードを使えない場合がある |

**推奨**: 「安定」が目的なら、**レポートは買い切り、マッチングは月額(年額プランで割引)**の組み合わせがよい。
- マッチングは利用者が集まらないと価値が出ない。まずは無料で、有料の必要が出てから課金するほうが解約率は下がる(**推定**)。
- 月額の価格は300〜500円が目安(**推定**)。
- 参考: 競合の Gamee は有料プランが**月980円**(依頼者からの共有情報。本調査では**未検証**)。980円なら手取りは約938円/月なので、25万円に必要な会員数は約267人に下がる。一方、後発の個人サービスが同じ価格で見劣りすると解約されやすいため、まずは500円前後で入り、機能が充実してから値上げする選択肢もある(**推定**)。

## 5. 法律面の注意点

### 5-1. 特定商取引法(レポート・有料プランの販売)
- インターネットで販売するときは、通信販売の広告表示義務がある(特商法第11条)。
- 氏名・住所・電話番号などは、**「請求があれば遅滞なく提供する」旨を表示し、実際に提供できる体制を整えていれば省略できる**。「遅滞なく」は、消費者が申し込みを決める前に間に合う程度とされる [26][27]。
- 省略しても、**販売価格・支払時期と方法・引渡時期・返品(キャンセル)の条件は省略できない**。デジタル商品は「購入後の返品不可」を明記する。
- 個人開発者が「請求があれば開示」の表記で Stripe の本番審査に通った実例がある。ただし、**開示用にバーチャルオフィスと連絡の取れる電話番号を用意しておくことが前提**で、運営者名は省略できない [28]。
- バーチャルオフィスの住所は「実際に事業を行っている住所」と言える場合に限って認められる。電話番号は発信専用ではなく、**実際に連絡がつく番号**が必要 [27]。
- 月額プランを始める場合は、最終確認画面に分量・価格・支払時期・契約期間・解約方法を表示する(2022年改正)[25]。

### 5-2. 景品表示法(ステマ規制、2023年10月施行)
- 規制の対象は広告主(事業者)だが、アフィリエイト広告は広告主の表示とみなされる。ASP は掲載者に「PR」「広告」などの表記を求めている [29][30]。
- **結果画面のおすすめ商品の近くに「PR」「広告」を明記する**。ハッシュタグに紛れ込ませたり、フッターだけに書いたりするのは不十分とされる [30]。
- Amazon アソシエイトでは「Amazonのアソシエイトとして、〇〇は適格販売により収入を得ています」という定型の表示が必要(規約。**2026年版の文言は未確認**)。
- 違反すると、広告主に措置命令が出て公表される。事業者の違反事例としては、大正製薬やロート製薬が他人の投稿をPR表記なしで自社サイトに転載したケースがある [30]。

### 5-3. 薬機法・健康増進法(目薬、プロテイン、サポーターなど)
- **薬機法の虚偽・誇大広告の禁止(第66条)は「何人も」が対象で、アフィリエイター本人も直接の規制対象になる** [31]。
- 目薬は医薬品なので、**承認された効能の範囲を超える表現**(「視力が回復する」「ゲームの疲れ目が治る」など)は書かない。「〇〇タイプのあなたにおすすめ」程度にとどめ、効能はパッケージの記載の範囲で表現する。
- 手首サポーターやブルーライトカットメガネは、医療機器でない限り「腱鞘炎を予防」「眼病を防ぐ」などの医療的な表現はしない。
- プロテインやエナジードリンクは食品なので、「痩せる」「集中力が上がる(医学的に)」など健康効果を断定する表現は健康増進法に抵触するおそれがある [31]。
- 違反すると、措置命令、課徴金、悪質な場合は刑事罰もある [31]。

### 5-4. そのほか
- **未成年の利用**: ゲーマーには10代も多い。未成年が親の同意なく結んだ契約は取り消される可能性がある(民法第5条)。購入画面に年齢確認と保護者同意のチェックを置くとよい。
- **マッチング機能**:
  - 異性交際を目的とする場合は、出会い系サイト規制法による届出と年齢確認が必要になる。
  - ユーザー同士のメッセージ機能があれば、電気通信事業の届出が必要になる可能性がある。
  - 「ゲームの相手探し」に目的を限っても、使われ方によってはリスクがある。
  - Stripe には禁止・制限業種の規定があり、マッチングや出会い系の扱いは**未確認のため要確認**。
- **税金**: 会社員の副業なら、所得(売上 − 経費)が年20万円を超えると確定申告が必要。売上が年1,000万円以下なら消費税は免税事業者のまま(B2C なのでインボイス登録は原則不要)。
- **X の収益化(Original Content Rewards)**:
  - X Premium の月額費用がかかり、条件を満たさない月は赤字になる。
  - 新制度では**オリジナルでない投稿(転載、軽い編集、コピー)は対象外**なので、ユーザーの診断結果の引用やリポストは収益につながらない。独自の分析や解説の投稿が必要になる [32][33]。
  - AI で自動生成しただけの投稿は対象外とする記述もある [33]。
  - 18歳以上であることが条件。
